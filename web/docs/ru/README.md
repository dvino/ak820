# Конфигуратор AK820

Будущий конфигуратор объединяет настройку AK820, бэкапы, обновление и возврат
штатной прошивки на одном сайте. Общее приложение для Windows, Linux и macOS
работает без интернета. При выборе Entropy сначала адаптируется нативный клиент,
а веб-версия разрабатывается параллельно; выпуск приложения не ждёт сайта.

В исходниках `web/` уже есть начальные модули офлайн-каталога возможностей и контракт протокола индикатора OS. Это основа разработки, а не готовый конфигуратор или помощник рабочего стола.

Разработка ведётся в ветке `web-dev`. Сначала проверяется Entropy: его
интерфейс на Rust/egui можно использовать в браузере через WebAssembly.
Запасной вариант — Pipette с существующей браузерной версией. Окончательный
выбор зависит от результатов прототипа.

Нативный клиент разрабатывается в `desktop-dev`; в `desktop` находится версия,
подготовленная к выпуску. Общие изменения сливаются между ветками разработки.

- [ТЗ](REQUIREMENTS.md): поведение и критерии приёмки.
- [План реализации](PLAN.md): этапы, зависимости и проверки готовности.
- [Состояние и обзор](REVIEW.md): исходники, выполненные проверки и ограничения.
