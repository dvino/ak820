# Контракты прошивки для AK Configurator

Исходники приложения и текущие планы ведутся в [AK Configurator](https://github.com/dvino/ak-configurator). Импортированные исходники Entropy ещё нужно адаптировать для AK820.

В этом каталоге находятся матрица выбора прошивки, возможности точных образов, описания на двух языках и контракты протокола. ТЗ и план ниже описывают основу интеграции с прошивкой; разработка приложения ведётся в отдельном репозитории. Начните с [контрактов прошивки](FIRMWARE-HANDOFF.md).

- [ТЗ](REQUIREMENTS.md): поведение и критерии приёмки.
- [План реализации](PLAN.md): этапы, зависимости и проверки готовности.
- [Состояние и обзор](REVIEW.md): исходники, выполненные проверки и ограничения.

Установка существующей прошивки описана в основной
[инструкции](../../../docs/ru/INSTALL.md).
