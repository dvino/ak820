# Сжатие полной прошивки

Цель — один образ `maximal` со всеми 14 дополнительными модулями и всеми
базовыми функциями. Число функций и лимиты хранения закреплены в
[плане](MAXIMUM-FUNCTIONALITY-PLAN.md). Общая цель пока не достигнута.

## Текущий образ: 30

`.build/resume30-default-keymap` занимает **44 400 байт CODE**. Экономия
относительно свежей сборки того же исходного кода без новой опции — **201 байт**.
Основная область CODE всё ещё переполнена на **4 047 байт**.
Диагностический образ не предназначен для установки. Физические окна CODE:
`[0x28a0,0x3000)` и `[0x3027,0xc700)`. Резервы загрузчика, NVM, макросов
и LED DMA сохранены.

| Измерение | Значение |
| --- | ---: |
| Занято CODE в нижнем / основном окне | 1 741 / 42 659 байт |
| Последний основной адрес | `0xd6ce` |
| Обычная XRAM + буфер записи | 2 946 + 64 = 3 010 / 3 072 байт |
| Ёмкость стека | 167 байт |
| Границы main / USB / timer / LED | 103 / 5 / 2 / 2 байт |
| Неразрешённые пути от этих корней | 0 |
| Условная сумма / запас | 165 / 2 байт |

Условная сумма: `103 + 2 + 3 × 17 + 5 + 2 + 2`. Учтены вход CRT в main
и все разные источники прерываний. Допущения о банках, OEM-обёртках,
маршрутизации и отсутствии повторного входа остаются открытыми.
Попадание в эту границу не подтверждает готовность прошивки.

SHA256 IHX: `e4f1d3f64583da25a189c048a9905213a926ca43ae005652ab98964ccc1d954f`.
[Машинный отчёт](../maximal-current.json) и [материалы прохода 30](../../audits/maximal-pass30-20261025/README.md)
связывают измерения с исходниками, инструментами, образами и ограниченными проверками.

## Заводские раскладки

Опция сборки `--compress-default-keymap` сжимает два слоя заводских раскладок.
По умолчанию она выключена. Текущий компилятор сначала вычисляет все
256 исходных 16-битных значений. Из них формируются 64 байта классов,
114 байт данных и 32 смещения строк. Итоговый образ содержит эти 210 байт
и декодер; исходная таблица размером 512 байт в линковку не попадает.
Экономия учитывает код декодера. Расход физической XRAM вырос на три байта.
Заводские назначения энкодера и таблицы LED сохранены. Формат шести
динамических слоёв в NVM и 16-битные значения протокола не изменены.

Генератор сохраняет сведения о текущих компиляторе, исходниках, собственном
коде, командах и зависимостях обеих фаз компиляции. Итоговый ASM и байты
образа сверяются с исходными значениями, вычисленными компилятором.
Подмена служебной фазы извлечения и изменение заголовка, используемого
только итоговой фазой, блокируются. Первые замечания ревью и их исправления
сохранены отдельно от итогового ревью всего пакета.

Свежая контрольная сборка maximal без опции занимает 44 601 байт CODE;
её IHX побайтно совпадает с проходом 29. Сборка `work` с опцией занимает
37 170 байт CODE и 2 557 байт физической XRAM. Экономия относительно свежей
контрольной сборки без опции — 191 байт CODE. Последний адрес — `0xba90`,
в конце основного окна остаётся 3 183 байта. Границы main/USB/timer/LED
сохранились: 98/5/2/2; условная сумма — 160 из 171 байта стека, запас — 11.
Эти контрольные сборки не заменяют выпущенный образ.

## Проверки и ограничения

Проходят семь тестов генератора, проверки реальной единицы компиляции и все
16 777 216 троек байтовых координат; нативный декодер проверен с ASan/UBSan.
В CPU-модели проходят по 275 вызовов точных образов с опцией и без неё:
все корректные заводские назначения и 19 некорректных граничных случаев.
Все занятые байты CODE сохранены. На 256 корректных чтениях декодер добавляет
42 260 инструкций в общей CPU-модели. Измерена только часть сброса, которая
читает заводские значения; полное время сброса и реальные миллисекунды
не измерены. Число заводских слоёв подтверждено статически: DCE удаляет
соответствующую функцию. Задержка обычного нажатия, долговечность записи
и работа на оборудовании не доказаны.
Декодер заводских значений используется при сбросе и инициализации раскладки;
обычное чтение динамических клавиш по-прежнему идёт через NVM.

Проверки стека, CRT и конечного читателя для текущего образа проходят.
Сертификаты контекста и ревью прохода 27 сохранены побайтно; текущие
защищённые ASM, инструменты, карта и происхождение повторно проверены,
проверка после линковки выполнена заново. Другие ограниченные CPU-проверки
проходят для 629 RGB setter, 576 Combo GET, 48 обновлений только кэша,
15 порядков разных IRQ и 256 селекторов LED. Все 4 047 занятых байт CODE
от `0xc700` сохранены в 20 сеансах. Проверка IRQ work сохраняет все
37 170 занятых байт CODE в 17 сеансах. Проверка CRT заканчивается
на входе в main и не охватывает основной цикл и полную инициализацию NVM.

Оба ассемблерных ядра NVM и прежние сокращения компилятора включены;
IRAM overlay выключен. Дальнейшее сокращение CODE, полные договорённости
о запуске и IRQ OEM, банках и закрытом коде записи, полные функциональные
регрессии и физическая проверка остаются открытыми. Команд устройству,
изменений установщиков, пакетов или релизов не было.

## Два дополнительных прохода и условие остановки

Оба запрошенных дополнительных прохода записаны в отчёте. В цепочке обработки
событий проверен один вариант. Его 12 288 ограниченных трасс совпали,
три ошибочных варианта отклонены, но CODE отдельного компонента вырос
с 565 до 627 байт. Вариант отклонён без интеграции и полной сборки.
Даже идеальное удаление всей обёртки размером 58 байт оставило бы рост
на четыре байта; это оценка компонента, а не результат линковки.

В протокольном проходе подходящий крупный вариант не найден. Патч и
компиляция не выполнялись. Три конкретных повторяющихся цикла занимают
42 байта инструкций; идеальный предел их совместного использования —
28 байт до накладных расходов. Эта оценка относится только к этим циклам
и не ограничивает все возможные переделки протокола.

Итоговая интегрированная экономия — 201 байт, ниже запрошенного ориентира
около 0,5 КиБ. Зафиксирована пауза после ревью пакета и подготовки передачи.
Общая цель не достигнута; глобальный минимум сжатия не заявлен.
