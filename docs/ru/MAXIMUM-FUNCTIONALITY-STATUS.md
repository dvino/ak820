функциями. Состав функций и объёмы хранилищ закреплены в

## Текущий образ: 27

`.build/resume27-classifier` занимает **44 699 байт CODE**. Основное окно
переполнено на **4 346 байт**. Это диагностический образ; устанавливать его
нельзя. Физические окна CODE остаются `[0x28a0,0x3000)` и `[0x3027,0xc700)`.
Резервы загрузчика, NVM, макросов и LED DMA сохранены.

| Измерение | Значение |
| --- | ---: |
| Занятый CODE: нижнее / основное окно | 1 741 / 42 958 байт |
| Последний адрес основного окна | `0xd7f9` |
| Обычная XRAM + буфер записи | 2 943 + 64 = 3 007 / 3 072 байт |
| Ёмкость стека | 167 байт |
| Границы main / USB / timer / LED | 103 / 5 / 2 / 2 байта |
| Неразрешённые пути от этих корней | 0 |
| Условная общая граница / запас | 165 / 2 байта |

Расчёт: `103 + 2 + 3 × 17 + 5 + 2 + 2`. Учтены вход CRT в main и все разные
источники прерываний. Полный контракт банков, обёрток OEM, маршрутизации и
запрета повторного входа ещё не закрыт. Этот расчёт не подтверждает готовность
прошивки.

SHA256 IHX: `96b7e63eba3e30b2d598b0f52e19b23c7a07ff5363194f87d565d359ab5da7f3`.
[Машинный отчёт](../maximal-current.json) и [проверки прохода 27](../../audits/maximal-pass27-20261025/README.md)
связывают размеры с исходниками, инструментами, образами и проверенными контекстами.

## Изменение и проверки

Классификатор USB raw-команд использует прямые ограниченные проверки вместо
вложенных switch. Разрешённые команды, запреты записи, обработка пакетов и
форматы хранения сохранены. Все 16 777 216 трёхбайтовых префиксов совпадают с
сохранённым эталоном switch. Обе намеренно ошибочные версии обнаружены.

Образ 26b воспроизведён побайтно из записанных входных данных. Его SHA256 IHX:
`47400365dfe8e7e56fd46a548938ca8c9024467ca13120f506cb7213e9f7ef10`.
Новый maximal экономит **48 байт связанного CODE** без изменения XRAM и ёмкости
стека. Отличающийся исторический исходник проверен по Git `cfd05a0`, а не выдан
за текущий. [Предыдущий пакет](../../audits/maximal-continuation-20261025/README.md)
сохраняется как историческое свидетельство.

Для точного образа проходят свежие проверки стека, CRT и конечная проверка
чтения. Ограниченная CPU-модель проходит 629 случаев RGB, 576 Combo GET,
48 обновлений только в кэше, 15 порядков разных IRQ и 256 селекторов LED.
Все 4 346 занятых байт от `0xc700` сохранены в 20 сеансах. CRT выполняется
только до входа в main. Основной цикл, инициализация NVM/настроек, физическая
запись flash и полная регрессия конфигурации этими проверками не покрыты.

Контрольный `work` из текущих исходников занимает 37 470 байт CODE и 2 554
байта физической XRAM: на 75 байт CODE меньше архивного контроля. Последний
адрес — `0xbbbc`, свободный хвост основного окна — 2 883 байта. Границы
main/USB/timer/LED — 98/5/2/2; условный итог — 160 из 171 байта стека, запас 11.
Свежая CPU-проверка проходит 15 порядков IRQ и 256 селекторов без изменения
занятого CODE. Этот контрольный образ не заменяет выпуск.

Оба ассемблерных ядра NVM и прежние сокращения компилятора включены; IRAM
overlay выключен. Открыты сокращение CODE, полный контракт OEM startup/IRQ и
банков, непрозрачный writer, полная регрессия и физическая проверка. Цель полной
прошивки ещё не достигнута. Запись на устройство, упаковка и изменение
установщиков или выпусков не выполнялись.
