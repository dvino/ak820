# Сжатие полной прошивки

Цель — один образ `maximal` со всеми 14 дополнительными модулями и базовыми
функциями. Состав функций и объёмы хранилищ закреплены в
[плане](../MAXIMUM-FUNCTIONALITY-PLAN.md).

## Текущий образ: 29

`.build/resume29-getter-bounds` занимает **44 601 байт CODE**. Основное окно
переполнено на **4 248 байт**. Это диагностический образ; устанавливать его
нельзя. Физические окна CODE остаются `[0x28a0,0x3000)` и `[0x3027,0xc700)`.
Резервы загрузчика, NVM, макросов и LED DMA сохранены.

| Измерение | Значение |
| --- | ---: |
| Занятый CODE: нижнее / основное окно | 1 741 / 42 860 байт |
| Последний адрес основного окна | `0xd797` |
| Обычная XRAM + буфер записи | 2 943 + 64 = 3 007 / 3 072 байт |
| Ёмкость стека | 167 байт |
| Границы main / USB / timer / LED | 103 / 5 / 2 / 2 байта |
| Неразрешённые пути от этих корней | 0 |
| Условная общая граница / запас | 165 / 2 байта |

Расчёт: `103 + 2 + 3 × 17 + 5 + 2 + 2`. Учтены вход CRT в main и все разные
источники прерываний. Контракт банков, обёрток OEM, маршрутизации и запрета
повторного входа ещё не закрыт. Этот расчёт не подтверждает готовность прошивки.

SHA256 IHX: `693fdcd928f2d84b32e19b858cdd6cce29b46d01ea5694403788da08bf3969f9`.
[Машинный отчёт](../maximal-current.json) и [проверки прохода 29](../../audits/maximal-pass29-20261025/README.md)
связывают размеры с исходниками, инструментами, образами и ограниченными проверками.

## Изменение и проверки

Две функции чтения по расположению передают вызовы AK820 напрямую существующим
обработчикам раскладки и энкодера. Эти обработчики уже проверяют границы.
Для остальных плат проверки в обёртках сохранены. Образ maximal экономит
**37 байт связанного CODE** против сохранённого прохода 28 без изменения XRAM
и ёмкости стека. Отличается только исторический `dynamic_keymap.c`; он
проверяется по полному записанному коммиту Git. Остальные зависимости
проверяются на месте. [Материалы прохода 28](../../audits/maximal-pass28-20261025/README.md)
не изменены.

Сравнение на ПК проходит 134 217 728 проверок в четырёх вариантах: AK820 на
обычном C, перевод текущего ассемблера AK820, C для другой платы и другая
геометрия для обычного C. Проверяются все байтовые входы, возвращаемые значения,
число и порядок адресов чтения EEPROM. Три ошибочных варианта отклонены.
Дополнительно ASan/UBSan проходит 33 554 432 проверки обычного варианта AK820.
Перевод ассемблера на ПК отличается от исполнения в CPU-модели целевого процессора.

Точные связанные функции чтения проходят 2 431 проверок в CPU-модели: все
допустимые клавиши матрицы, все байты направления для каждого допустимого слоя
энкодера и неверные граничные значения. Проверяются чтения, результат, состояние
кэша, стек и защитные байты. Все занятые байты CODE (44 601) сохранены. Каждый вызов
использует одну заранее заполненную страницу кэша. Новые ошибки чтения, грязные
переходы между страницами, запись flash и IRQ не входят в эту проверку.
Проверка setter из прохода 28 относится к прежнему образу; это не новая проверка
setter для прохода 29.

Проверки стека, CRT и конечных путей чтения точного образа проходят. Сертификаты
контекста прохода 27 и их рецензии сохранены побайтно. Защищённый ASM компилятора,
инструменты, map и происхождение перепроверены; postlink для прохода 29 проверен
заново. Остальные ограниченные CPU-проверки проходят: 629 случаев RGB setter,
576 Combo GET, 48 обновлений только в кэше, 15 порядков разных IRQ и 256 селекторов
LED. Все 4 248 занятых байт начиная с `0xc700` сохранены в 20 сеансах.
CRT выполняется только до входа в main; основной цикл и инициализация
NVM/settings не проверяются.

Контрольный `work` из текущих исходников занимает 37 361 байт CODE и 2 554 байта
физической XRAM, экономя 31 байт CODE против сохранённого work прохода 28.
Последний адрес — `0xbb4f`, свободный хвост основного окна — 2 992 байта.
Границы main/USB/timer/LED — 98/5/2/2; условная сумма — 160 из 171 байта стека,
запас — 11. Ограниченная CPU-проверка IRQ сохраняет весь занятый CODE в 17 сеансах.
Контрольная сборка не заменяет опубликованный образ.

Оба ассемблерных ядра NVM и прежние сокращения компилятора сохранены; IRAM overlay
выключен. Ещё нужны сокращение CODE, полный контракт OEM startup/IRQ и банков,
проверка непрозрачного writer, полная регрессия настроенной сборки и проверка
на аппаратуре. Цель полной прошивки не закрыта. Устройство, установщики,
пакеты и выпуски не изменялись.
