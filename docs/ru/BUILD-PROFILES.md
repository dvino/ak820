# Профили сборки

Для настольного конфигуратора определены девять готовых профилей. Выбирается профиль
целиком; приложение не объединяет отдельные переключатели модулей. Профиль
`work` выбран по умолчанию. В него входят управление NKRO, One Shot, Space Cadet,
Leader, динамические макросы и управление индикатором OS. В `work` выключены
Mouse Keys и режим Mac/PC; для этих функций выберите `mouse` или `system`.

Список профилей и включённых модулей берётся из реестра прошивки. Старые имена
профилей разработки сохранены в низкоуровневом CLI для повторения прежних сборок,
но не предлагаются в настольном конфигураторе. Ни один профиль не включает все
дополнительные модули.

| Профиль | Для чего | Модули пакета сверх общих функций |
| --- | --- | --- |
| `work` | Обычная работа; профиль по умолчанию | Leader, динамические макросы, управление индикатором OS |
| `essential` | Основные функции для набора текста | Управление индикатором OS |
| `typing` | Набор текста с Auto Shift | Auto Shift, управление индикатором OS |
| `mouse` | Управление указателем и прокруткой с клавиатуры | Mouse Keys, управление индикатором OS |
| `mouse-typing` | Mouse Keys и Auto Shift | Mouse Keys, Auto Shift, блокировка GUI, управление индикатором OS |
| `system` | Переключение модификаторов для Windows, Linux и macOS | Блокировка GUI, перестановка Ctrl/GUI, перестановка Alt/GUI для Mac/PC, управление индикатором OS |
| `tap-dance` | Действия на нажатие и удержание | Tap Dance |
| `key-overrides` | Замена клавиши при выбранных модификаторах | Key Overrides |
| `settings` | Изменение поддерживаемых интервалов и параметров | QMK Settings |

В каждый пакет также входят общие средства: управление NKRO, One Shot для
модификаторов и ограниченный Space Cadet. Во всех профилях есть одинаковая
основа: шесть слоёв, 16 макросов Vial с буфером 8192 байта, восемь двухклавишных
Combo, компактная обработка нажатия/удержания, настройка энкодера, мультимедийные
и системные клавиши, NKRO-отчёты, Caps Word, Repeat и Alt Repeat, Grave Escape, Tri Layer,
RGB-эффекты и VialRGB Direct. [Каталог функций](FEATURES.md) объясняет поведение
и ограничения. В [матрице модулей](MODULE-MATRIX.md) перечислены совместимость
и измеренные ресурсы всех девяти профилей.

## Сборка профиля

Запускайте команды из корня репозитория. Для каждой сборки создавайте новый
каталог под `qmk-8051-ak820`. Если `--profile` не указан, выбирается `work`.
Для девяти готовых профилей автоматически включается проверенная оптимизация
коротких вызовов с закреплённым SDCC 4.6.0.

```sh
python tools/configure_firmware.py list
python tools/configure_firmware.py build --profile work \
  --build-dir qmk-8051-ak820/.build/work \
  --toolchain toolchains/sdcc-4.6.0 \
  --qmk-bin qmk-8051-ak820/.venv/bin/qmk \
  --python qmk-8051-ak820/.venv/bin/python
```

Команда `list` отдельно показывает `release_profiles` — девять готовых профилей —
и профили совместимости для прежних сборок разработки. Команда `build` связывает
образ, проверяет два окна CODE и размещение RAM, определяет границы стека и
прерываний точного образа, затем запускает автономные регрессионные проверки.
Неизвестная необходимая граница или переполнение останавливают сборку. Успешные
офлайн-проверки не подтверждают работу физической клавиатуры и не одобряют образ
для выпуска.

Проверить готовую сборку:

```sh
python tools/configure_firmware.py inspect --build-dir qmk-8051-ak820/.build/work --toolchain toolchains/sdcc-4.6.0
```

Повторить проверку runtime для неё:

```sh
python tools/configure_firmware.py check-runtime \
  --build-dir qmk-8051-ak820/.build/work \
  --toolchain toolchains/sdcc-4.6.0
```

Объём проверки описан в [проверке стека](RUNTIME-STACK.md). Результаты автономных
проверок и состояние выпуска приведены в [статусе](STATUS.md). Опубликованный образ `v0.6.0-alpha.3` не изменён.
