# Профили сборки

Конфигуратор собирает все восемь сочетаний трёх дополнительных функций.
Профиль `full` — кандидат alpha.3; остальные семь остаются профилями разработки.
Квалификация исходников и независимая проверка правила выпуска завершены.
Кандидат не опубликован и не проверен на устройстве; выпуск ещё ожидает
нативного CI. Текущее состояние описано в [статусе](STATUS.md).

## Сборка профиля

Запускайте команды из корня репозитория. Выберите профиль и новый каталог
сборки внутри `qmk-8051-ak820`:

```sh
python tools/configure_firmware.py list
python tools/configure_firmware.py build --profile standard \
  --build-dir qmk-8051-ak820/.build/new \
  --toolchain toolchains/sdcc-4.6.0 \
  --qmk-bin qmk-8051-ak820/.venv/bin/qmk \
  --python qmk-8051-ak820/.venv/bin/python
```

Можно выбрать любой профиль из списка. Вместо `--profile` используйте
`--features` со списком из `nkro-control`, `one-shot`, `space-cadet`; без
значений выбирается базовый набор. Например:

```sh
python tools/configure_firmware.py build --features nkro-control one-shot \
  --build-dir qmk-8051-ak820/.build/nkro-one-shot \
  --toolchain toolchains/sdcc-4.6.0 \
  --qmk-bin qmk-8051-ak820/.venv/bin/qmk \
  --python qmk-8051-ak820/.venv/bin/python
```

`--profile` и `--features` — альтернативные параметры. Команда `build`
связывает образ, проверяет размещение в обоих окнах CODE и RAM, затем
запускает обычные регрессионные проверки и host/CPU-наборы выбранной функции
на точном образе. В каталоге сборки сохраняются конфигурация, квалификация и
результаты наборов профиля. Эти автономные проверки не подтверждают работу
физической клавиатуры и безопасность выпуска.

Чтобы повторно проверить сборку, выполните:

```sh
python tools/configure_firmware.py inspect --build-dir qmk-8051-ak820/.build/new --toolchain toolchains/sdcc-4.6.0
```

`inspect` заново проверяет размещение ресурсов и идентификатор образа.
`package` разрешает только полный квалифицированный профиль `full`, если
доказательство исходников и независимое правило совпадают. Остальные семь
профилей нельзя упаковывать.

## Профили

Во всех профилях остаются шесть слоёв, 16 макросов Vial, восемь двухклавишных
Combo, компактный tap-hold, карта энкодера, мультимедиа, отчёты NKRO, Caps Word,
Repeat и Alt Repeat, Grave Escape, Tri Layer, RGB-эффекты и VialRGB Direct в
RAM. Время Combo — 40 мс, компактный tap-hold — 200 мс. QMK Settings во время
работы отключены. Дополнительные функции выбираются при сборке.

| Профиль | Дополнительные функции |
| --- | --- |
| `standard` | Нет |
| `nkro` | `nkro-control` |
| `one-shot` | `one-shot` |
| `nkro-one-shot` | `nkro-control`, `one-shot` |
| `space-cadet` | `space-cadet` |
| `nkro-space-cadet` | `nkro-control`, `space-cadet` |
| `one-shot-space-cadet` | `one-shot`, `space-cadet` |
| `full` | `nkro-control`, `one-shot`, `space-cadet` |

Управление NKRO включает `NK_ON`, `NK_OFF` и `NK_TOGG`. Режим отчёта
сохраняется до перезапуска; после него используется сохранённый режим или
режим по умолчанию. Переключение очищает удерживаемые клавиши и ожидающие
действия — отпустите клавиши перед повторным нажатием. Записи во flash нет.
Другие действия Magic не включены.

One Shot поддерживает сочетания модификаторов. Нажмите и отпустите OSM, затем
клавишу: модификаторы действуют до отпускания этой клавиши. Можно заранее
набрать несколько модификаторов. Удержание OSM работает как обычный
модификатор. Пока целевая клавиша нажата, новая OSM работает только при
удержании. Работают матричные клавиши и оба направления энкодера. One Shot
для слоёв, тайм-аут, фиксация и tap-toggle отсутствуют. Назначить OSM клавише
через Vial можно; отправить виртуальное событие OSM из Vial или макроса — нет.

Space Cadet назначает `SC_LSPO` на левый Shift при удержании и Shift + `9`
(`(`) при коротком нажатии; `SC_RSPC` — на правый Shift при удержании и Shift
+ `0` (`)`) при коротком нажатии; `SC_SENT` — на правый Shift при удержании и
Enter при коротком нажатии. Эти клавиши используют существующий компактный
tap-hold и его владение модификаторами. Space Cadet нельзя назначить входом
Combo. Полный движок Space Cadet из QMK не включён. Проверенные граничные
случаи и ограничения приведены в [отчёте Space Cadet](../../audits/rc6/roadmap-max-20261024/space-cadet.md).

Ресурсы зависят от полного связанного образа. Измеряйте каждый профиль по его
отчёту: затраты функций не складываются. Для `full` доказательство выпуска ограничивает стек основного пути 93 байтами,
CRT — 2 байтами, а трёх IRQ-путей вместе — 61 байтом. Всего используется 156
из 162 байт, запас — 6 байт. Доказательства и ограничения приведены в [статусе](STATUS.md).

## Отложенные функции

В первоначальный перечень входили 11 кандидатов. Три имеют ограниченную реализацию; профиль `full` включает их все, остальные
восемь отложены. Наличие команды в Vial само по себе не означает, что прошивка
поддерживает функцию.

| Отложенная функция | Что нужно проверить |
| --- | --- |
| Tap Dance | У upstream-пробы есть несовместимость ABI обработчиков и смещение фиксированного хранилища Combo; компактная реализация должна сохранить его адрес. |
| Key Overrides | У upstream-пробы есть несовместимость ABI обработчиков; остаются вопросы владения модификаторами и взаимодействий с Repeat, Caps Word и макросами. |
| Mouse Keys | Upstream-проба превышает основное окно CODE на 1 381 байт; нужен меньший объём функции и проверка времени сканирования. |
| Auto Shift | Нужно заменить диапазоны `case` явными метками C вместо GNU-диапазонов; upstream-проба превышает основное окно CODE на 2 081 байт. |
| QMK Settings в Vial | Нужно реализовать новую версионированную запись настроек, типизированную копию, восстановление и миграцию. Совместимый план сохраняет существующие смещения Combo; см. [план настроек](../../audits/rc6/roadmap-max-20261024/qmk-settings-plan.md). |
| Magic | Отдельно проверить перестановку модификаторов, управление GUI и сохранение. |
| Leader | Ограничить длину последовательности, время ожидания и доступные действия. |
| Динамические макросы | Ограничить RAM для записи и проверить воспроизведение; макросы Vial остаются доступны. |

Console и Command остаются отключены. Имитация сбоев нужна только для тестов.
Диагностика FD00/FD01 доступна только для чтения. Конфигуратор не открывает
USB и не отправляет команды клавиатуре.

Подробности проб и измеренные результаты приведены в
[отчёте по функциям](../../audits/rc6/roadmap-max-20261024/feature-probes.md).
