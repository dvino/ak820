# Профили сборки

Конфигуратор собирает и проверяет экспериментальные профили. Пакеты для
установки пока не создаются: ещё не доказан предельный расход стека с учётом
прерываний и не проверен перенос настроек на новые образы через установщик.
Поэтому команда `package` останавливается. Дальнейшие задачи перечислены
в [планах](ROADMAP.md), результаты — в
[отчёте проверки профилей](../../audits/rc6/configurable-20261024/qualification.md).

## Сборка профиля

Запускайте команды из корня репозитория. Выберите один профиль и новый каталог
сборки внутри `qmk-8051-ak820`:

```sh
python tools/configure_firmware.py list
python tools/configure_firmware.py build --profile standard \
  --build-dir qmk-8051-ak820/.build/new \
  --toolchain toolchains/sdcc-4.6.0 \
  --qmk-bin qmk-8051-ak820/.venv/bin/qmk \
  --python qmk-8051-ak820/.venv/bin/python
```

Замените `standard` на `nkro` или `one-shot`, чтобы выбрать соответствующую
функцию. Вместо `--profile` можно указать `--features` без значения (без
дополнительных функций), `nkro-control` или `one-shot`. Например,
`--features nkro-control` выбирает NKRO. Не включайте обе дополнительные
функции вместе: образ не помещается в основное окно CODE. Параметры `--profile` и
`--features` являются альтернативными способами выбора.

Команда `build` собирает образ, проверяет оба окна CODE и
размещение RAM, затем запускает автономный набор регрессионных тестов на том
же образе. В каталоге сборки создаются `configuration-report.json`,
`qualification.json` и `profile-tests/results.json`. Проверки профиля включают
ограничения конфигуратора, а для выбранной опции — её тесты на хосте и
исполняемом коде. Эти проверки не подтверждают работу физической
клавиатуры. Чтобы повторно проверить существующую сборку, выполните:

```sh
python tools/configure_firmware.py inspect --build-dir qmk-8051-ak820/.build/new --toolchain toolchains/sdcc-4.6.0
```

Команда `inspect` повторно проверяет размещение кода, память и хеши файлов.
Команда `package` принимает те же параметры каталога и компилятора, но
останавливается до создания установочного пакета по причинам, указанным выше.

## Состав профилей

Во всех профилях остаются шесть слоёв, 16 макросов Vial, восемь двухклавишных
Combo, Grave Escape и поддержка отчётов NKRO. Время Combo остаётся равным
40 мс, компактный интервал tap-hold — 200 мс. QMK Settings во время работы
отключены; выбор профиля — отдельный параметр сборки.

| Профиль | Дополнительная функция | Поведение и ограничение |
| --- | --- | --- |
| `standard` | Нет | Только основной набор функций. |
| `nkro` | Управление NKRO (`NK_ON`, `NK_OFF`, `NK_TOGG`) | Выбирает режим отчёта клавиатуры до перезапуска. После перезапуска используется сохранённый режим или режим по умолчанию. Переключение сбрасывает удерживаемые клавиши и ожидающие действия; отпустите эти клавиши перед повторным нажатием. Записи во flash нет. |
| `one-shot` | Модификаторы One Shot (`OSM`) | Нажмите и отпустите OSM, затем другую клавишу: модификатор действует до отпускания этой клавиши. Можно заранее набрать несколько модификаторов. Удержание OSM работает как обычное удержание модификатора. Пока целевая клавиша нажата, новая OSM работает только при удержании. Поддерживаются матричные клавиши и оба направления энкодера. OSL, тайм-аут, фиксация и tap-toggle отсутствуют. Назначать OSM клавише через Vial можно; виртуальные нажатия OSM из Vial и макросов не поддерживаются. |

Использование ресурсов определяется итоговым образом. Измеряйте оба
окна CODE и RAM по отчёту каждой сборки: затраты функций не складываются
линейно, поэтому разница между двумя профилями не предсказывает затраты
третьего. Конфигуратор проверяет границы размещения, но не заявляет, что
допустимый запас стека во время работы подтверждён.

## Состояние функций из планов

Два из 11 кандидатов уже имеют компактную реализацию. Остальные отложены.
Наличие элемента управления в клиенте ещё не означает поддержку в прошивке.

| Кандидат | Текущий статус или ограничение |
| --- | --- |
| One Shot | Реализовано только ограниченное поведение модификаторов, описанное выше; вариант со слоями и другие действия не включены. |
| Tap Dance | Отложено: нужно проверить динамические записи, владение общим путём ввода и размер полного образа. |
| Key Overrides | Отложено: нужно проверить владение модификаторами и взаимодействие с Repeat, Caps Word и макросами. |
| Mouse Keys | Отложено: нужно проверить отчёты мыши, время сканирования и размер полного образа. |
| Auto Shift | Отложено: нужно проверить взаимодействие с tap-hold, Combo и Caps Word. |
| Управление NKRO | Реализованы только три описанных выше действия смены режима отчёта; все действия Magic не включены. |
| QMK Settings в Vial | Отключено во время работы. Параметры upstream с ID 1, 2, 7, 8, 18, 19, 20 и 21 учтены в перечне, но это не обещание, что элементы управления будут приниматься. Структура upstream занимает 36 байт и меняет динамическую раскладку данных Combo по адресу `0x658`; перед включением нужно проверить версионирование, отдельную типизированную резервную копию, значения по умолчанию и миграцию. Время Combo и tap-hold остаётся фиксированным: 40 мс и 200 мс. |
| Magic | Отложено: требуется отдельная проверка совместимости и сохранения перестановок модификаторов и управления клавишей GUI. |
| Leader | Отложено: нужно ограничить длину последовательности, время ожидания и доступные действия. |
| Space Cadet | Отложено: нужно проверить владение и отмену в tap-hold. |
| Динамические макросы | Отложено: нужно проверить RAM для записи и воспроизведение. Имеющиеся 16 слотов макросов Vial остаются доступными. |

### Исключения для диагностики

Console и Command остаются отключены. Имитация сбоев относится к тестам,
а не к функциям профиля. Диагностическое чтение FD00/FD01 остаётся в прошивке.
Сам конфигуратор не открывает USB и не отправляет команды клавиатуре.
