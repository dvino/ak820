# Сборка профилей

По умолчанию выбирается `main`. Десять текущих составов описаны в [каталоге профилей](profiles/README.md), их функции — в [матрице](MODULE-MATRIX.md). Старые составы сохранены только для воспроизведения разработки; прежний `typing` доступен как `legacy-typing`.

Команды выполняются из корня репозитория. Для каждого образа нужен новый каталог сборки, закреплённый SDCC 4.6.0 и сертификат контекста исходников/IRQ. Сертификат создаётся по свежей исходной сборке и полному разбору всех IRQ; его нельзя заменять файлом от другого состава при несовпадении защищённых модулей.

```sh
python tools/configure_firmware.py list
python tools/configure_firmware.py build --profile main \
  --build-dir qmk-8051-ak820/.build/main \
  --toolchain toolchains/sdcc-4.6.0 \
  --qmk-bin qmk-8051-ak820/.venv/bin/qmk \
  --python qmk-8051-ak820/.venv/bin/python \
  --parameter-spills-context /path/to/reviewed-context.json
```

Для текущих профилей автоматически применяются сжатие начальных раскладок, короткие вызовы, ASM-ядра чтения/обновления NVM и слов раскладки, доказанное удаление лишних сохранений параметров и регистров, общие хвосты и вынос повторяющихся фрагментов. Проверка связывает всю цепочку с точными исходниками, инструментами и образом.

Сначала проверяются запуск, границы стека и все включённые IRQ точного образа, затем полные регрессионные наборы. Неизвестный путь или превышение памяти блокирует результат. Офлайн-проверки не подтверждают физическую работу клавиатуры. См. [проверку стека](https://github.com/dvino/ak820/blob/v0.6.0-beta.2/docs/RUNTIME-STACK.md) и [Status](STATUS.md).
