# Настройки QMK

Меняйте небольшой набор параметров времени и поведения через Vial.

Профили с `AK820_QMK_SETTINGS` предоставляют перечисленные настройки через Vial.
Изменения сохраняются после перезапуска. Сброс возвращает значения из таблицы.
Он не меняет раскладку, макросы, Combos и профиль NKRO.

| QSID | Настройка | Размер | Допустимые значения | По умолчанию |
| ---: | --- | ---: | --- | ---: |
| 1 | Модификаторы Grave Escape | 1 байт | ALT=1, CTRL=2, GUI=4, SHIFT=8; сумма битов, 0–15 | 0 |
| 2 | Время ожидания Combo | 2 байта | 1–1000 мс | 40 мс |
| 3 | Режим Auto Shift | 1 байт | маска `0x1d`: бит 0 — включён, бит 2 исключает знаки пунктуации, бит 3 — цифры, бит 4 — буквы | 1 |
| 4 | Время удержания Auto Shift, только в профилях с компактным Auto Shift | 2 байта | 1–1000 мс | 175 мс |
| 6 | Тайм-аут One Shot | 2 байта | 0–30000 мс; 0 — без тайм-аута | 0 |
| 22 | Набор правил Caps Word | 1 байт | 0 — английский, 1 — русский | 0 |
| 7 | Время выбора нажатия или удержания | 2 байта | 1–1000 мс | 200 мс |
| 18 | Задержка tap-code | 2 байта | 0–100 мс | 0 мс |
| 19 | Задержка нажатия Caps Lock | 2 байта | 0–100 мс | 80 мс |

Задержки tap-code и Caps Lock действуют в функциях `tap_code()` и
`tap_code16()`: например, при отправке символов строки и старых действий
макросов `SS_TAP_CODE`. Компактные Mod-Tap, Layer-Tap, Space Cadet и Tap Dance
передают события напрямую и не используют эти задержки. Расширенные действия
макросов Vial down/up также используют собственное заданное время.

QSID 3 по умолчанию равен `1`; его маска задаёт включение, исключение знаков
пунктуации, цифр и букв битами 0, 2, 3 и 4 соответственно. Значения QSID 3, 6
и 22 применяются сразу после успешной операции настройки, в том числе при
явной записи прежнего значения. Только запрос прежнего значения не записывает
flash и не сбрасывает ввод. Сохранённые значения остаются после перезапуска. Остальные настройки применяются
после успешного сохранения. При фактическом изменении настройки активные выходы
освобождаются, ожидающие решения отменяются, а удерживаемые физические клавиши
блокируются до отпускания. Ошибка хранилища останавливает запись; новое значение
не применяется. Автоматического повтора или отката после ошибки нет.

Жесты включения Caps Word доступны во всех десяти профилях. Коды `0x7e00`,
`0x7e01` и `0x7e02` выбирают английские правила, русские правила или
переключают набор правил до перезапуска; раскладку компьютера они не меняют.

## Формат и протокол

Используется отдельная запись платы без включения общего `QMK_SETTINGS`.
Combos остаются по адресу `0x658`. Запись из 24 байт занимает `0x6a8..0x6bf`,
целиком помещается на одной странице журнала размером 64 байта и сохраняется
через проверяемую транзакцию NVM.

| Байты | Содержимое |
| --- | --- |
| 0–1 | ASCII `QS` |
| 2 | Версия записи, 2 |
| 3 | Длина данных, 15 |
| 4 | Возможности, `0x7f` |
| 5 | Биты Grave Escape |
| 6–7 | Время Combo |
| 8–9 | Время выбора нажатия или удержания |
| 10–11 | Задержка tap-code |
| 12–13 | Задержка Caps Lock |
| 14–15 | Время Auto Shift; хранится и в профилях без QSID 4 |
| 16 | Биты Auto Shift (та же маска, что у QSID 3) |
| 17 | Набор правил Caps Word (`0` английский, `1` русский) |
| 18–19 | Тайм-аут One Shot |
| 20–21 | Резерв, нули |
| 22–23 | CRC16-CCITT, полином `0x1021`, начальное значение `0xffff`, по байтам 0–21 |

Во всех двухбайтовых значениях, включая CRC, младший байт идёт первым.
До загрузки значений проверяются заголовок, диапазоны, резерв и CRC всей записи.
Полностью нулевая или стёртая запись выбирает значения по умолчанию без записи.
Другая неверная запись также выбирает значения по умолчанию, но фиксирует ошибку
схемы и блокирует дальнейшую запись. Корректная запись версии 1 читается и обновляется в RAM без записи при запуске.
Первая изменённая настройка сохраняет версию 2. В версии 1 байты 16–21 равны нулю.

Query возвращает поддерживаемые двухбайтовые QSID больше указанного ID и
заполняет остаток значениями `0xffff`. Get и Set возвращают ноль при успехе,
`-1` при неизвестном ID, недостаточном буфере или недопустимом значении. Set
также отклоняет запрос при ошибке хранилища. Буфер может быть шире значения:
пакеты Vial содержат заполнение в конце. QSID 3 и 4 доступны только при `AK820_COMPACT_AUTOSHIFT`; QSID 6 требует One Shot. QSID 22 есть во всех профилях с QMK Settings.

Проверка на ПК `qmk-8051-ak820/util/test_ak820_settings.c` проверяет начальные
значения, валидацию, сохранение, отмену ввода, отсутствие лишней записи и ошибку
хранилища. Она моделирует API и не доказывает восстановление flash после потери
питания или физические задержки клавиатуры. Стек, прерывания точного образа
и поведение устройства проверяются отдельно.
