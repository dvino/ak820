# Хранение настроек модулей

Все десять профилей текущего кандидата используют схему NVM `0x082003`. API
низкоуровневого упаковщика по умолчанию использует `0x082002`, если целевая
схема не задана; сборка профилей выбирает схему отдельно. Схема `0x082003`
добавляет типизированное хранилище для восьми записей Tap Dance, восьми записей
Key Override и QMK Settings. Это описание исходного кода, а не опубликованного
или квалифицированного выпуска.

Шесть слоёв раскладки, таблица энкодера по адресу `0x640`, восемь Combo по
десять байт с `0x658`, метаданные макросов `0x7f0` и буфер макросов
`0x800..0x27ff` сохраняют прежнее размещение. Адреса расширений ниже указаны
от начала NVM. Адреса и кодировка заголовка не изменились.

| Данные | Адрес | Формат |
| --- | --- | --- |
| QMK Settings | `0x6a8..0x6bf` | Запись 24 байта с версией |
| Tap Dance | `0x6c0` | Восемь записей по десять байт `<5H` |
| Key Overrides | `0x740` | Восемь записей по десять байт `<HHHBBBB` |

Записи 0–5 размещаются по адресу `base + index*10`, записи 6–7 — по адресу
`base + 64 + (index-6)*10`. Запись не пересекает страницу журнала размером
64 байта. Дополнительные байты зарезервированы.

Запись `QS` длиной 24 байта имеет три версии: v1 — длина 11/возможности
`0x3f`, v2 — 15/`0x7f`, v3 — 17/`0xff`. Во всех версиях CRC16-CCITT
(начальное значение `0xffff`) вычисляется по байтам 0–21 и хранится little
endian в байтах 22–23. Общие поля: Grave Escape (байт 5, 0–15), Combo term
(6), tapping term (8), задержка нажатия (10), задержка Caps Lock (12) и
Auto Shift timeout (14). Значения по умолчанию: 0, 40, 200, 0, 80 и 175;
term/timeout допускают 1–1000 мс, задержки — 0–100 мс. Версия 2 добавляет
QSID 3 в байте 16 (1 байт, 0–29; допустимы биты 0, 2–4) и QSID 6 в байтах
18–19 (2 байта, 0–30000) и QSID 22 в байте 17 (однобитовое булево
значение). Версия 3 сохраняет QSID 22 в байте 17 и добавляет QSID 23 — Leader
timeout 1–1000 мс little endian в байтах 20–21; значение по умолчанию берётся
из точного целевого образа. Прошивка трактует
полностью нулевую или `ff`-запись как значения по умолчанию; повреждённая
непустая запись вызывает ошибку. Офлайн-проверка копии не должна выводить из
этого неизвестные исходные значения: пустые v2/v3 отклоняются, если QSID 22
нельзя аутентифицировать.

Выходы Tap Dance допускают KC_NO либо базовый код с модификаторами ниже
`0x2000`, с младшим байтом `0x04..0xa4` или `0xe0..0xe7`. Нулевой term
означает 200 мс; явный term допускает 1–32767 мс. Пустая запись Key Override
состоит из нулей. Непустая требует trigger `0x04..0xa4`, replacement KC_NO
либо базовый код с модификаторами и младшим байтом `0x04..0xa4`, маску слоёв
1–63 и хотя бы один из битов 0–2 options. Бит 6 запрещён.

## Профили, перенос и резервная копия

Каждый профиль хранит все восемь записей Tap Dance, все восемь записей
Key Override и запись QMK Settings. QMK Settings доступны во всех десяти
профилях. Tap Dance активен только в `mmo`, `onehand`, `creative` и
`shortcuts`. Key Overrides активны в `main`, `game`, `typing`, `code`, `pointer`,
`shortcuts` и `multios`; в `mmo`, `onehand` и `creative` они неактивны.
Неактивная таблица сохраняется, но установщик не читает и не восстанавливает её
значения как активные настройки. Если копия содержит неактивные значения,
которые нельзя воспроизвести в целевом профиле, запись останавливается заранее.

`pack.migrate_vial_nvm(..., target_build_id=pack.EXTENSION_BUILD_ID)` явно
переносит схемы NVM `0x082001` или `0x082002` в `0x082003`. Поля schema02,
включая непустые Combo, копируются; проверки вместимости макросов schema01
сохраняются. Записи настроек переходят только вперёд: v1→v2/v3, v2→v3;
понижение запрещено. Для добавления QSID 23 нужно значение Leader по умолчанию
из точного целевого образа. Для schema03 низкоуровневые `pack` и
`verify_payload` требуют явной целевой схемы; обычное значение упаковки —
schema02.

Для этих профилей установщик использует типизированный формат
`ak820-settings-backup-2`. Он содержит все таблицы расширений и настройки,
а также проверяет точные хеши образа и метаданные профиля. Заявленные функции
должны совпадать с выбранным профилем. Старые копии
`ak820-settings-backup-1` могут инициализировать хранилище расширений, только
если целевые таблицы пусты, а QMK Settings имеют значения по умолчанию. Копию
схемы03 нельзя восстановить в схему02. Точные образы и ограничения автономного
переноса приведены в [статусе](STATUS.md).

Поддержка формата и схемы не допускает образ как источник настроек или цель
восстановления. Нужна отдельная проверка точного образа по политике из раздела
[Сохранение и восстановление настроек](SETTINGS-BACKUP.md). Загрузка v3,
планирование восстановления и протокольная запись для текущего кандидата
остаются заблокированы; поддержка офлайн-кодека не квалифицирует образы и не
разрешает запись настроек.

Палитра Direct RGB и временное состояние модулей в копию не входят. Если
целевой профиль не может воспроизвести значение, восстановление останавливается
до первой записи. Проверка формата не подтверждает физическую работу клавиш или
сохранность настроек после отключения питания.
