# Матрица модулей

Прошивка модульная: все реализованные функции одновременно не помещаются в память контроллера. Десять готовых составов меняют отдельные возможности `main` на другие. QMK Settings есть во всех профилях.

Во всех профилях также есть шесть слоёв, 16 сохраняемых макросов Vial с общим буфером 8192 байта, восемь двухклавишных Combo, Mod-Tap/Layer-Tap, настройка энкодера, мультимедийные клавиши, Caps Word, Repeat/Alt Repeat, Tri Layer и встроенные RGB-эффекты. Отсутствие Direct сохраняет общее управление режимом, цветом, яркостью и скоростью; передача отдельных кадров для каждого светодиода требует Direct.

Размеры модулей не складываются: проверяется каждый полный образ после всех оптимизаций. Старые измерения девяти профилей нельзя переносить на эти составы. Точные размеры и доказательства для выпуска приводятся в Status.
