# Матрица модулей и профилей

Для приложения подготовлен каталог из **девяти профилей**. Выбирается один профиль целиком. Профиль по умолчанию — **`work`**. Каталог покрывает все 14 существующих дополнительных модулей; перебор произвольных сочетаний не предлагается.

Состав берётся из [реестра прошивки](../../qmk-8051-ak820/util/ak820_profiles.py), машинные данные — из [firmware-matrix.json](../../web/firmware-matrix.json). Краткие описания и ограничения находятся в [каталоге функций](FEATURES.md). Состояние проверок и выпуска указано в [Status](STATUS.md).

## Профили

| Код | Профиль | Назначение |
| --- | --- | --- |
| W | `work` | Рекомендуемый профиль общего назначения. Добавляет Leader и два временных слота динамических макросов, а также управление индикатором OS. Mouse Keys и перестановки для Mac/PC нет. |
| E | `essential` | Компактный профиль на каждый день: управление NKRO, One Shot и Space Cadet. |
| T | `typing` | Подходит, если удержание поддерживаемых букв и цифр должно вводить вариант с Shift. |
| M | `mouse` | Управляйте указателем и прокруткой с помощью клавиш. |
| MT | `mouse-typing` | Для управления мышью с клавиатуры и ввода вариантов с Shift долгим нажатием поддерживаемых клавиш. |
| S | `system` | Для настройки модификаторов в Windows, Linux и macOS. Перестановки сбрасываются при перезапуске. |
| TD | `tap-dance` | Назначайте разные поддерживаемые действия для нажатия, удержания и повторных нажатий. |
| KO | `key-overrides` | Заменяйте выбранную клавишу при совпадении заданных условий модификатора и слоя. |
| QS | `settings` | Меняйте поддерживаемые параметры Combo, нажатия/удержания, Grave Escape и другие настройки через Vial. |

Все девять профилей содержат шесть слоёв, 16 макросов Vial с общим буфером 8192 байта, восемь двухклавишных Combo, Mod-Tap/Layer-Tap, назначения обоих направлений энкодера, мультимедиа и системные клавиши, отчёты NKRO, Caps Word, Repeat и Alt Repeat, Grave Escape, Tri Layer, RGB-эффекты и VialRGB Direct в RAM. Управление NKRO, One Shot и Space Cadet также есть во всех девяти профилях.

## Память

Размеры получены из финальных IHX/MAP/MEM каждой сборки с SDCC 4.6.0 и проверенным режимом short calls. Размеры отдельных модулей не складываются: оценивается связанная прошивка целиком. Свободные байты в двух окнах CODE нельзя переносить между окнами.

| Профиль | CODE, байт | Свободно main / low | XRAM / 3072 | Расход / ёмкость стека | Запас стека |
| --- | ---: | ---: | ---: | ---: | ---: |
| `work` | 40386 | 22 / 92 | 2676 | 162 / 165 | 3 |
| `essential` | 38660 | 1748 / 92 | 2564 | 162 / 167 | 5 |
| `typing` | 39281 | 1127 / 92 | 2581 | 162 / 166 | 4 |
| `mouse` | 39523 | 885 / 92 | 2594 | 162 / 167 | 5 |
| `mouse-typing` | 40285 | 123 / 92 | 2614 | 162 / 166 | 4 |
| `system` | 39082 | 1326 / 92 | 2567 | 162 / 166 | 4 |
| `tap-dance` | 40173 | 311 / 16 | 2795 | 166 / 166 | 0 |
| `key-overrides` | 40464 | 20 / 16 | 2734 | 162 / 162 | 0 |
| `settings` | 40075 | 409 / 16 | 2640 | 162 / 166 | 4 |

Расчёт стека учитывает основной код, запуск и все включённые прерывания точного образа. У `tap-dance` и `key-overrides` запас стека равен нулю: текущая граница соблюдается, но любые добавления требуют нового расчёта. Результаты и ограничения проверок приведены в [статусе](STATUS.md). XRAM не включает отдельные 512 байт DMA. Хранилище макросов и NVM не относятся к CODE.

## Профиль по умолчанию

`work` добавляет к общей базе Leader, динамические макросы и управление индикатором OS из приложения-компаньона. Leader запускает один из 16 сохранённых макросов сочетанием префикса и клавиши; динамические макросы позволяют быстро записать две короткие временные последовательности. Это дополняет навигационные слои, команды редактора и часто повторяемые действия.

Mac/PC и управление мышью исключены из профиля по умолчанию. Auto Shift выделен в `typing`: он меняет привычный ввод удерживаемых клавиш. Тяжёлые расширения Tap Dance, Key Overrides и QMK Settings предлагаются отдельными профилями. Для `work` сделаны только небольшие оптимизации существующего кода; новые модули не добавлялись.

## Контракт приложения

`firmware-matrix.json` связывает профиль, флаги компиляции, доступные модули, размеры и SHA256 точного образа. Состояния измерения, проверки стека, регрессии и допуска к установке разделены. `release_approved` и `installable` для этих кандидатов остаются `false`; имя профиля не даёт разрешения на запись.

`module-descriptions.json` содержит названия, короткие описания, ограничения и ссылки на руководство на русском и английском. Описание модуля также служит введением в соответствующий раздел. Для восстановления настроек требуется точный `settings_identity` упакованного CODE, полученный с проверенным исходным OEM-образом. До упаковки поле равно `null`; переходы между разными образами разрешаются только явными парами хешей. Подробности — в [передаче для десктопа](../../web/docs/ru/FIRMWARE-HANDOFF.md).

### Поля для приложения

Для начального выбора используется `default_profile`. Необязательный CLI-режим
`--resolve` фильтрует существующие пакеты по нужным модулям и выбирает пакет с
наименьшим числом лишних модулей. Он не меняет профиль по умолчанию и не собирает
новое сочетание.

| Поле | Назначение |
| --- | --- |
| `profiles[].id`, `profile` | Постоянные ID пакетов; по ним подставляются переведённые описания. |
| `configuration` и `build_recipe` | Точные флаги модулей, схема, значения по умолчанию и режим short calls. |
| `capabilities.optional_modules` | Включение только тех элементов управления, которые реализованы в образе. |
| `capabilities.dynamic_entries` | Восемь Combo; восемь Tap Dance или Key Overrides только в соответствующем пакете. |
| `capabilities.runtime_qmk_settings_ids` | Доступные ID изменяемых настроек; сохранённые, но неактивные поля исключены. |
| `identity` и `resources` | Хеши файлов и точные размеры CODE, XRAM и стека управления. |
| `measurement_status`, `runtime_status`, `offline_tests_status` | Отдельные результаты сборки и проверок. |
| `feature_pairs` | Профили, содержащие каждую из 91 пары дополнительных модулей. |
| `settings_identity`, `settings_transitions` | Контракт настроек точного упакованного образа и явно допущенные пары восстановления. |
| `release_approved`, `installable` | Отдельный допуск; автономные проверки не включают эти флаги. |

В ZIP кандидатов используются пути `profiles/<id>/firmware/application.ihx`,
`.map` и `.mem`, а также отчёты конфигурации и проверок. Манифест перечисляет все
файлы и их SHA256. В ZIP девять приложений прошивки; это ещё не комплект
установщика и не полный набор свидетельств для независимой повторной проверки.
Полные сборки, листинги, результаты анализа и журналы сохранены в техническом
отчёте, на который ссылается Status.
