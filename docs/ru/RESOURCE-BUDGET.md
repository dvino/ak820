Каждая сумма включает постоянный кадр CRT и все три разных источника IRQ.
Минимальный запас — один байт. Изменённый образ должен пройти расчёт заново;
одного максимума из CPU-теста недостаточно. См. [условия проверки](RUNTIME-STACK.md).

Dynamic Macros остаётся неподдерживаемым сочетанием. Новые образы не допущены
к выпуску.

## Опубликованный образ

| Ресурс | опубликованный образ alpha.3 |
| --- | ---: |
| Конец main CODE | `0xc546` |
| Окна CODE | `[0x28a0,0x3000)` и `[0x3027,0xc700)` |
| Свободно в конце окна | 441 main / 16 low |
| XRAM | 2 637 / 3 072 байта |
| Начальный SP / выделение для стека | `0x5d` / 162 байта |
| Слои / макросы / общее хранилище макросов | 6 / 16 / 8 192 байта |

Выделение для стека не является доказанной максимальной глубиной во время
работы. Свободные байты двух окон CODE нельзя объединить. NVM и хранилище
макросов не являются исполняемым CODE.

Опубликованный образ alpha.3 `full` измерен как полная связанная сборка с обоими окнами
CODE и RAM. Основной путь использует 93 байта стека, CRT — 2 байта, три пути
IRQ вместе — 61 байт. Всего используется 156 из 162 байт, остаётся 6 байт.
Числа относятся только к точному квалифицированному образу и не подтверждают
работу физического устройства.

Эти числа стека относятся только к опубликованному образу alpha.3. Они не
применимы к изменённым профилям разработки. Их функции описаны в
[профилях сборки](BUILD-PROFILES.md), а принятые базовые измерения и ограничения
компактных функций — в [техническом отчёте](../../audits/rc6/leader-next-20261024/README.md).
