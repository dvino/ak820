# Память и число слоёв

В текущем профиле остаются шесть слоёв, шестнадцать макросов и общее хранилище макросов на 8192 байта. Четыре слоя — только контролируемое сравнение, не настройка выпуска. Указатель заголовка журнала в XDATA включён в исходники; его офлайн-сборка — кандидат для разработки, который не продвигали и не устанавливали. Точный образ, закреплённый для резервного копирования настроек, остаётся образом стабильного выпуска.

## Текущие измерения

Кандидат из текущих исходников: `feac6dae864e801b6177fb8c57a23a65c59b850c5dd3ce84dfb2abb853058cc8`. Образ стабильного выпуска: `f1c4347e60ca5f7ea6c557debe60272259f4ddf9acfac9897fa992210bf7ef2e`.

| Образ | CODE всего | Основное окно CODE | Нижнее окно CODE | XRAM | Начальный SP / выделенный стек |
| --- | ---: | ---: | ---: | ---: | ---: |
| Кандидат из исходников | 38 069 (36 261 основное + 1 808 нижнее) | занято 36 261 из 38 617; 2 356 адресов без данных IHX | занято 1 808 из 1 888; 80 адресов без данных IHX | занято 2 066 из 3 072; свободно 1 006 | 0x62 / 157 байт |
| Стабильный выпуск | 38 100 (36 292 основное + 1 808 нижнее) | занято 36 292 из 38 617; 2 325 адресов без данных IHX | занято 1 808 из 1 888; 80 адресов без данных IHX | занято 2 067 из 3 072; свободно 1 005 | 0x62 / 157 байт |

Число адресов без данных IHX в окне не гарантирует наличие пригодного непрерывного участка. Пять адресов `0x302a..0x302e` зарезервированы в HOME и входят в число адресов без данных IHX основного окна; это не свободное место CODE. Ёмкость стека — предел выделенной области, а не доказательство максимального расхода стека на всех путях. Изменение указателя экономит 31 байт CODE и один байт XRAM относительно стабильного образа. Отклонённая проба с выражением задержки добавила три байта CODE и не включена. Сборка и офлайн-ревью описаны в [отчёте](../../audits/rc6/bounded-optimization-20261023.md) и [JSON-отчёте](../../audits/rc6/bounded-optimization-20261023.json); сохранённые доказательства — в [каталоге материалов](../../audits/rc6/bounded-evidence-20261023/). Кандидат не установлен и не продвинут в выпуск. Состояние квалификации указано в [статусе](STATUS.md).

Сравнения ниже используют исходную компоновку RC6 до изменений `12260272…e114`. Это отдельные исторические контролируемые сравнения, не текущие сборки из таблицы выше.

Один слой матрицы занимает `16 × 8 × 2 = 256` байт EEPROM, энкодер —
`1 × 2 × 2 = 4`. Два слоя освобождают **520 байт логических адресов NVM**.
Но начало макросов остаётся `0x800`, NVM — `0x2800`, кэш страницы — 64 байта.
Без изменения схемы увеличивается пустой промежуток, а не CODE или макросы.

В скомпилированных исходных раскладках и энкодере уже только два слоя.
Состояние слоёв уже 8-битное. Изолированная сборка четырёх слоёв дала **39 262
CODE и 2071 XRAM**, ровно как шесть: **экономия в обоих ресурсах нулевая**.
Меняется только логический промежуток NVM.

Адрес энкодера переместится с `0x640` на `0x440`. Со старым schema ID туда
попадут байты старого слоя 4. Нужны новая схема и миграция либо намеренное
сохранение старого адреса. Tri Layer помещается в 0–3, но назначения слоёв
4/5 требуют отдельной политики. Рекомендация: оставить шесть слоёв в этом выпуске.

Для RGB простая маска цветов места не экономит. Компактная CIE-кривая кандидата
содержит 32 записи вместо 256: 224 байта таблицы до учёта машинного кода.
Wire/EEPROM HSV не меняются. В рабочем диапазоне до 160 максимальная проверенная
ошибка канала — 8/255; 0, 80 и 160 точны. Затухание добавляет 82 байта возрастов
и двухбайтовую отметку времени. Сравнительная линковка дала **216 байт экономии
CODE**: 39 478 с полной кривой против 39 262 с компактной, при одинаковых функциях.
Упаковка Direct HSV могла бы сэкономить 82 RAM, но добавляет код и потери цвета;
этот вариант не включён.

Локальная правка Breathing интерполирует ту же таблицу из 32 записей один раз
на кадр. Новой таблицы нет, преобразование остальных эффектов не изменено.
CPU-модель проверила все 161 поддерживаемое значение кривой: отклонение от
полной кривой не превышает единицу. Host-тест при яркости 160 показывает
69 уровней вместо 20 и максимальный скачок 2 вместо 8 при шаге фазы 1.
Это офлайн-результаты, а не проверка видимой плавности или времени на устройстве.
