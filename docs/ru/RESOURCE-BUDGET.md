# Память и число слоёв

Опубликованная и установленная прошивка — `v0.6.0-alpha.3`. Её точный образ и
доказательства выпуска приведены в [статусе](STATUS.md). Все текущие профили
разработки содержат изменения исходников после этого образа и не прошли
квалификацию выпуска.

## Текущие сборки разработки

Матрица от 2026-10-24 прошла автономные проверки для всех одиннадцати профилей
и двенадцати вариантов сборки. Полные измерения и точные хеши образов приведены
в [техническом отчёте](../../audits/rc6/compact-next-20261024/README.md).

| Сборка | CODE, байт | Свободно в конце main / low | Выделено XRAM |
| --- | ---: | ---: | ---: |
| Опубликованная alpha.3 `full` | 40 043 | 441 / 16 | 2 637 |
| Оптимизированная `full` | 39 145 | 1 339 / 16 | 2 638 |
| Оптимизированная `full --short-calls` | 38 907 | 1 577 / 16 | 2 638 |
| `full-mouse` | 40 029 | 455 / 16 | 2 670 |
| `full-auto-shift` | 39 758 | 726 / 16 | 2 655 |
| `full-mouse-auto-shift --short-calls` | 40 403 | 81 / 16 | 2 687 |

Доступно 3 072 байта XRAM, отдельно от фиксированного резерва DMA в 512 байт.
Текущим вариантам `full` выделено 163 байта стека; максимальное использование
стека во время работы ещё не доказано. Новому совместному профилю нужен
`--short-calls`; по умолчанию эта опция выключена. Эти числа не переносят
разрешение выпуска alpha.3 на изменённые образы.

## Исторические сравнения

| Ресурс | исторический образ alpha.2 |
| --- | ---: |
| Конец main CODE | `0xc687` |
| Окна CODE | `[0x28a0,0x3000)` и `[0x3027,0xc700)` |
| Свободно в конце окна | 120 main / 67 low |
| XRAM | 2 621 / 3 072 байта |
| Начальный SP / выделение для стека | `0x5f` / 160 байт |
| Слои / макросы / общее хранилище макросов | 6 / 16 / 8 192 байта |

Выделение для стека не является доказанной максимальной глубиной во время
работы. Свободные байты двух окон CODE нельзя объединить. NVM и хранилище
макросов не являются исполняемым CODE.

В прежнем контролируемом сравнении переход с шести слоёв на четыре сэкономил
ноль байт CODE и XRAM, освободив 520 логических адресов NVM. Эти адреса не
перешли в хранилище макросов; база энкодера при этом переместилась бы, поэтому
нужны решение о схеме и миграции. В проекте оставлено шесть слоёв. Подробности
старого сравнения и измерений RGB сохранены в датированном
[техническом исследовании](../../audits/rc6/optimization-deep-analysis-20261023.md);
они не описывают текущий образ выпуска.

Опубликованный образ alpha.3 `full` измерен как полная связанная сборка с обоими окнами
CODE и RAM. Основной путь использует 93 байта стека, CRT — 2 байта, три пути
IRQ вместе — 61 байт. Всего используется 156 из 162 байт, остаётся 6 байт.
Числа относятся только к точному квалифицированному образу и не подтверждают
работу физического устройства.

Эти числа стека относятся только к опубликованному образу alpha.3. Они не
применимы к изменённым профилям разработки. Их функции описаны в
[профилях сборки](BUILD-PROFILES.md), а текущие измерения и ограничения
компактных функций — в [техническом отчёте](../../audits/rc6/compact-next-20261024/README.md).
