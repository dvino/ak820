# Каталог возможностей

`tools/build_capability_catalog.py` описывает точные сборки для настольного
приложения. Каталог не разрешает запись настроек, установку прошивки или
публикацию выпуска. Для записи каталога нужны проверки стека основной
программы, запуска и прерываний для точного образа, журналы основных тестов
и тесты профиля. Одного профиля исходного кода недостаточно.

Готовый [каталог возможностей девяти образов](../../web/capability-catalog.json)
содержит проверенный контракт типов хранилища и настроек. Он связывается с
[firmware-matrix.json](../../web/firmware-matrix.json) по точному SHA256 IHX;
ID профиля используется для отображения. Его `code_identity` двух связанных
окон не заменяет идентификатор постоянного упакованного CODE, необходимый
для допуска восстановления настроек.

Поле `module_storage` имеет формат `ak820-module-storage-contract-1`.
Объект `modules` различает сохранённые данные и доступные команды. Схема03
резервирует восемь строк Tap Dance, восемь строк Key Overrides и запись
QMK Settings, даже когда соответствующий модуль не включён. Пакеты `tap-dance`, `key-overrides` и `settings` включают каждый свой
модуль расширения. Старые имена `full-*` остаются в низкоуровневом CLI для
повторения прежних сборок. Приложение должно показывать элементы управления по
`enabled_entries` и `enabled_qsids`. Наличие сохранённых данных само по себе
не означает поддержку команды. Для схемы02 расширения не объявляются. Девять
готовых пакетов и их измеренные ресурсы перечислены в [матрице модулей](MODULE-MATRIX.md).

Поля настроек содержат QSID, размер, порядок байтов little endian, диапазон,
значение по умолчанию, адрес в NVM и активных потребителей. QSID 4 хранится,
он зарезервирован: ни один из девяти готовых пакетов не включает одновременно
QMK Settings и Auto Shift. Его нельзя показывать как доступный элемент управления.
Задержки нажатия относятся только к указанным функциям. Они не меняют compact
tapping, Space Cadet, жесты Tap Dance и явные действия down/up макросов Vial.
Tap Dance использует время своей строки; ноль означает 200 мс. QSID 7 на
него не влияет. Проверку записей выполняет общий кодек.

Контракт также описывает адреса строк с отступами между страницами, команды,
ограничения и правила восстановления. Для переноса нужно явно выбрать
целевую схему. Непустые Combo схемы02 сохраняются; вместимость макросов
проверяется. Копию схемы03 нельзя восстановить в схему02. Различия неактивных
таблиц или настроек без команды записи запрещают восстановление до первой
записи. Полный формат приведён в [описании хранения](MODULE-STORAGE.md).

Проверка каталога выполняется без устройства. Работа физических клавиш и
сохранность при отключении питания требуют отдельных проверок. Контракт
исходного кода и его тесты не создают проверенную запись для сборки, которая
ещё не прошла обязательные проверки.
