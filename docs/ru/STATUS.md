# Состояние проекта

## Время проверок CI, 2026-10-26

Workflow выпуска повторно использует успешную проверку преобразований, пока
все входные данные совпадают. Первые проверки при сборке пакетов распределены
между четырьмя процессами. При каждом обращении хеши вычисляются заново;
тесты прошивки и проверки выпуска продолжают выполняться. См.
[CI и выпуски](https://github.com/dvino/ak820/blob/main/docs/ru/CI.md).

Свежая локальная сборка и квалификация `multios` завершились за 7 минут
4 секунды: прошли 28 базовых наборов, 331 юнит-тест без пропусков и
37 дополнительных наборов. Байты IHX не изменились; граница стека всей
программы — 160/171 байт. Общий прогон host-тестов прошёл 281 тест.
Отдельный замер проверки образа показал 22,974 секунды при первом вызове
и 2,454 секунды при неизменных входных данных. Предыдущий
[прогон GitHub](https://github.com/dvino/ak820/actions/runs/40268741259) занял
84 минуты 6 секунд, из них команда сборки и квалификации `multios` —
58 минут 6 секунд. Это разные машины; результат не является замером
ускорения всего CI. Новый прогон десяти профилей в GitHub и сборки
установщиков на Windows и Linux ещё не выполнены. Команды устройству
не отправлялись. Отчёты и ревью находятся в `audits/ci-speed-20261026/`.

## Beta.2: десять профилей

В beta.2 входят десять профилей: `main`, `game`, `mmo`,
`typing`, `code`, `pointer`, `onehand`, `creative`, `shortcuts` и `multios`. По
умолчанию выбран `main`. Установщик позволяет
выбрать профиль; для каждого есть инструкции
на русском и английском. См. [каталог
профилей](profiles/README.md) и [матрицу
модулей](MODULE-MATRIX.md).

Каждый новый точный образ прошёл проверку
границ стека для основного кода, запуска
и всех включённых прерываний до полной
регрессии. Для каждого образа прошли 28 базовых
наборов и 331 юнит-тест без пропусков, а также
32–37 дополнительных наборов. Для десяти
образов это 280 базовых и 335 дополнительных
запусков наборов. Повторные общие тесты не
считаются отдельными тестами. Свежие сборки
сохранили те же байты IHX, что и образы,
использованные для проверки упаковки и
переноса настроек. [Отчёт
квалификации](https://github.com/dvino/ak820/blob/v0.6.0-beta.2/audits/rc6/beta2-release-20261025/qualification-final.json)
связывает идентификаторы образов
и результаты. [Предварительная проверка
упаковки](https://github.com/dvino/ak820/blob/v0.6.0-beta.2/audits/rc6/beta2-release-20261025/packing-preflight.json)
содержит автономные проверки пакетов; [проверка
переходов](https://github.com/dvino/ak820/blob/v0.6.0-beta.2/audits/rc6/beta2-release-20261025/transition-preflight.json)
охватывает 130 автономных случаев: десять переходов профиля в себя и 120
явно перечисленных переходов вперёд. Для источников alpha.2, alpha.3 и beta.1
`work` указан переход в каждый профиль beta.2; между профилями beta.2 разрешены
только проверенные переходы. [Запись исправления alpha.3](https://github.com/dvino/ak820/blob/v0.6.0-beta.2/audits/rc6/beta2-release-20261025/alpha3-transition-fix.json)
связывает исторические IHX `d505d4f420f745dbd5e98a0e3638c8f3ae6d7719c8729dad274595b71b641f18`
и CODE `01f0f7a979d8cfa8217b3bba333758ae3509cf7f3f8e35fbffb1ed034b808e5d`;
в ней записаны десять автономных переносов из alpha.3 и отдельные проверки
нестандартных значений. Неподдерживаемые и неуказанные переходы отклоняются.
Эти проверки не подтверждают работу на устройстве.
