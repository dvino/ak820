# Состояние проекта

Обновлено 23.10.2026. RC6 на SDCC 4.6 установлена; печать подтверждена отдельно.
Разовая консольная прошивка выполнена с настройками пакета. Прежние настройки
сохранены локально и не восстановлены.

## Исходники и сборка

Поддерживается только ajazz/ak820:vial. Чужие клавиатуры, ненужные платформы,
старое приложение, инструменты исследования родной прошивки и прежние выпуски
убраны после внешнего резервного копирования. SDCC и LUFA устанавливаются
отдельно из закреплённых архивов. См. [сборку](BUILD.md) для другого ПК.

Основной сборщик выбирает SDCC 4.6.0; 4.4.0 доступен для сравнения.
Свежая сборка: qmk-8051-ak820/.build/source-trim-production-sdcc46-20261023/.
Занято 38 100 байт CODE (36 292 в основном окне, 1 808 в нижнем), 2 067 XRAM.
Доступно 157 байт стека линковщика. Свободно 2 405 байт CODE в двух окнах.
Карта дополнительно считает пять резервных адресов HOME, отсутствующих в IHX.
SHA256 IHX: f1c4347e60ca5f7ea6c557debe60272259f4ddf9acfac9897fa992210bf7ef2e.
Образ побайтно совпал с проверенной прошивкой до очистки.
Независимо проверены 465 входов и 76 артефактов.

Пакет исходного установщика: releases/rc6.
SHA256 манифеста: f181619c824bd93778bffe0e842d15bb0917ed5af15f65bd294ec4c461773402.
Команда verify проходит. Это не разрешение на аппаратную запись.
[Ревью сборки](../../audits/rc6/source-trim-release-review-20261023.md).

Windows-архив пока прежний: dist/AK820-sdcc46-breathing-20261023.zip.
SHA256: a80338dafdc06f39534db53d4cf23eecdfa18383883549248fdea8f769035fa6.
В нём прежние проверенные host-инструменты. После правки упаковщика он ещё
не пересобран. Публичной загрузки и push не было.

## Проверки и устройство

Тот же образ до очистки прошёл 19 host/CPU-наборов и отдельные CPU-проверки.
Общий тест SDCC для bool через near-указатель падает в двух случаях из
шестнадцати на обоих компиляторах. Затронутый шаблон не найден в проверенных
используемых путях; бэкпорт остаётся условной будущей задачей.

После очистки прошли семь Windows-наборов без устройства, семь тестов LUFA,
восемь SDCC, три теста выбора версии и двенадцать тестов упаковщика.
Новый host/CPU-прогон завершился: 17 наборов прошли сразу; два сбоя запуска
закрыты отдельными Linux-проверками (19 тестов адаптера и 75 пакетных тестов).
Исходный отчёт с ошибками сохранён без изменения итогового кода.

Результат установки: host/runs/20261023-as-is-flash/. SHA256 образа:
a1b8beec9a2a675c955bac946339e31f1823e17cdfb60f4755796e550530c711.
SHA256 полной ROM: 56b2de776924c48bda6d08a2604edc8ab94f24e5ec7365f7b584c0fe7dd70fc5.
Одна последовательность команд загрузчика 1,2,3,4,5 выполнена. После запуска
проверены весь CODE, манифест, защищённые области, исходные настройки и чистый
журнал без ошибок хранилища. Печать подтверждена отдельно.

Набор только для чтения прошёл: 498 назначений клавиш, 12 позиций энкодера,
16 макросов с областью 8192 байта и 82 записи светодиодов. Отчёт:
host/runs/20261023-sdcc46-installed-readonly/report.json. Запись настроек
не запрашивалась. Загрузка макросов, сохранение RGB, физическая работа
энкодера/подсветки и сохранение после снятия питания на этом образе не проверены.

## Что осталось

Протокол сохранения в прошивке отменён. Незакоммиченный эксперимент
сохранён снаружи и удалён из дерева. Локальный экспорт и восстановление
будут использовать существующие команды Vial в общем модуле GUI/CLI.
Реализация отложена; заморозку, токены и записи импорта в прошивку не добавлять.
[План реализации](../../audits/rc6/general-update-implementation-plan-20261023.md).

Direct Control пока исследуется; удалять его без разрешения нельзя.
Другие оптимизации, индикаторы и Windows-помощник остаются в
[плане](ROADMAP.md). Дерево прошло независимое ревью, создан чистый коммит c1779a8a. Старое
локальное наследство сохранено снаружи и удалено из истории; pack занимает
1,84 МиБ. Merge/push ещё впереди. См. [результат очистки](../../audits/rc6/clean-history-result-20261023.md).
