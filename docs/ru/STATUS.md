# Состояние проекта

## Квалификация прошивки v0.6.0-beta.3, 2026-10-26

Квалификация точных образов завершена для всех десяти профилей с неизменными
сочетаниями модулей. Каждый профиль прошёл 28 основных наборов квалификации
и 351 модульный тест без пропусков. Отдельные регрессионные проверки профилей прошли от 32 до 37
дополнительных наборов. Границы стека учитывают запуск, основной код и все

Direct v1 включён в профили `main`, `game`, `mmo` и `creative`. Он позволяет
читать палитру из 82 цветов HSV, хранящуюся только в RAM, и атомарно передавать
полные кадры. В `game` и `mmo` блокировка GUI по умолчанию выключена. При её
включении W пульсирует с циклом яркости 2000 мс; активный или начальный слой
выше нуля имеет приоритет и включает постоянный свет.

В выпуск входят Python-установщики для Windows и Linux x86_64. GUI-установщик
не включён; приложение-компаньон будет отдельным. Проверки прошивки, сборки
пакетов и независимое одобрение фиксируются отдельно для каждого точного
образа. Указатель исходных доказательств: `audits/beta3-direct-20261026/README.md`.
Тег GitHub, отправка в репозиторий и публикация не выполнялись. Клавиатура
не прошивалась, настройки не записывались. Физические задержки USB,
светодиодов и DMA, а также поведение при потере питания и сохранность данных
не проверены.
