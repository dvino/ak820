# Состояние проекта

Обновлено 2026-10-25. [v0.6.0-beta.1](https://github.com/dvino/ak820/releases/tag/v0.6.0-beta.1)
опубликована. Автономные установщики Windows и Linux x86_64 устанавливают `work`.
В выпуск также входят матрица девяти профилей, возможности точных образов,
описания на двух языках, файлы SHA256 и инструкции установки EN/RU.
Для установки одобрен только `work`; остальные восемь профилей остаются кандидатами.

Все три [задачи CI](https://github.com/dvino/ak820/actions/runs/40137874411)
прошли на исходниках `bef20f8`. Контрольное скачивание подтвердило хеши всех
16 публичных файлов. Данные GUI и CLI обеих платформ совпадают с одним
одобренным комплектом прошивки; Linux CLI также прошёл локальный запуск справки
и автономную проверку. См. [запись публикации](../../audits/rc6/beta1-release-20261025/publication.json),
[проверку скачанных файлов](../../audits/rc6/beta1-release-20261025/published-assets-check.json)
и [независимое ревью пакетов](../../audits/rc6/beta1-release-20261025/native-review.md).
Повторные запуски dev и тега отменены после выбора успешного запуска main
на тех же исходниках; эти отмены не означают сбой проверки прошивки.

релиза во время первого запуска. Первая остановка из-за смены исходников

## Каталог прошивок

В каталоге для приложения девять готовых профилей. По умолчанию выбран `work`:
к общим функциям добавлены Leader, динамические макросы и индикатор OS под
управлением приложения-компаньона. Mac/PC, управление мышью и Auto Shift в
`work` не включены. Каталог покрывает все 14 существующих дополнительных
модулей.  [Матрица модулей](MODULE-MATRIX.md)
содержит состав и точные размеры сборок; [профили](BUILD-PROFILES.md) описывают
назначение каждого пакета.

На зафиксированных исходниках `7125bee` все девять точных образов прошли проверку памяти, стека основного кода, запуска
и прерываний, а затем полную автономную проверку. Для каждого прошли 28 общих
наборов с 286 юнит-тестами без пропусков и ещё 26–33 профильных набора. Всего
выполнены 252 общих и 255 дополнительных наборов; повторные запуски общих
тестов не считаются разными тестами. Проверка стека выполняется до регрессий
каждого образа. [Сводка](../../audits/rc6/beta-catalog-20261024/summary.json) и
[технический отчёт](../../audits/rc6/beta-catalog-20261024/README.md) связывают
образы, размеры, журналы и результаты независимой проверки.

`work` занимает 40 386 байт CODE и 2676 байт XRAM; свободны 22 байта основного
окна и 92 байта нижнего. Расчётный расход стека — 162 из 165 байт, запас — три.
У `tap-dance` расход 166 из 166, у `key-overrides` — 162 из 162: текущая граница
соблюдается с нулевым запасом. Любое изменение кода требует новой проверки
точного образа. Эти результаты не подтверждают физические задержки или
поведение при потере питания. Прежняя матрица из 24 профилей и 26 вариантов
не подтверждает новые образы.

Общие ёмкости сохранены: шесть слоёв, 16 макросов Vial с общим буфером 8192
байта и восемь двухклавишных Combo. `tap-dance`, `key-overrides` и `settings`
используют схему `0x082003`, остальные шесть — `0x082002`. Зарезервированное
хранилище расширения не включает отсутствующий модуль. См.
[хранение модулей](MODULE-STORAGE.md).

JSON-файлы в `web/` сохраняют исходные снимки кандидатов. Для определения
допуска к установке и точного идентификатора упакованных настроек `work`
используется [firmware-matrix.json из выпуска](https://github.com/dvino/ak820/releases/download/v0.6.0-beta.1/firmware-matrix.json).
Одобрена только строка `work`. Другие переходы настроек между образами запрещены,
пока доверенный каталог явно не разрешает точную пару исходного и целевого хеша.
[Контракты прошивки](../../web/docs/ru/FIRMWARE-HANDOFF.md) описывают возможности
и правила ссылок на справку.

## Последняя записанная установка

Последняя записанная установка — [alpha.3](https://github.com/dvino/ak820/releases/tag/v0.6.0-alpha.3), 2026-10-24.
IHX: `d505d4f420f745dbd5e98a0e3638c8f3ae6d7719c8729dad274595b71b641f18`.
В этой работе beta.1 не устанавливалась.

Alpha.3 установлена CLI из скачанного опубликованного Linux-архива. Один переход
в загрузчик, одна запись и один перезапуск завершились успешно. Точный CODE
и полный манифест приложения после запуска совпали с релизным образом.
Второе новое физическое подтверждение разрешило восстановление настроек.
Проверены 498 клавиш, 12 назначений энкодера, 16 слотов макросов, восемь
сохранённых байт RGB и восемь слотов Combo; выполнены десять штатных команд
записи. Полное чтение сохранённой NVM прошло. После обновления подтверждена
работа печати.

Первое ожидание подтверждения истекло до входа в загрузчик и стирания.
Операция остановилась без повтора; новая попытка была отдельно разрешена.
Свежие копии, подтверждения обновления и восстановления, хеши приватных
результатов записаны в [отчёте устройства](../../audits/rc6/alpha3-release-20261024/device-result.json).
OEM-образы восстановления, настройки и записи обмена остаются приватными.

Отдельные физические проверки NKRO, One Shot, Space Cadet и энкодера,
сохранение после отключения питания, сбои питания и ручная работа GUI
не проверялись.

## AK Configurator

Исходный код конфигуратора ведётся в отдельном репозитории [dvino/ak-configurator](https://github.com/dvino/ak-configurator). Исходники Entropy были импортированы туда, но ещё не адаптированы для AK820. В этом репозитории нет сборки конфигуратора для AK820, проверки на устройстве или развёртывания. См. [требования](https://github.com/dvino/ak-configurator/blob/main/docs/REQUIREMENTS.md), [план](https://github.com/dvino/ak-configurator/blob/main/docs/PLAN.md) и [ревью переноса](https://github.com/dvino/ak-configurator/blob/main/docs/REVIEW.md). Локальные проверки документов и независимое ревью охватили оба набора изменений; они не подтверждают готовность приложения или прошивки.
