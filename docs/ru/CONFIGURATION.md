# Настройка клавиатуры

Используйте совместимый Vial, предварительно закрыв OEM-конфигуратор.
Прежний `AK820-Vial-v2` — адаптер другого протокола, не интерфейс этого порта.

Выберите клавишу на изображении клавиатуры в Vial и назначьте ей действие.
Доступны шесть слоёв с номерами от 0 до 5. Прозрачная клавиша берёт действие
из нижнего активного слоя. `KC_NO` ничего не отправляет. При настройке верхнего
слоя оставьте клавишу, которой можно перейти на другой слой. Для каждого слоя
можно отдельно задать действия энкодера при вращении в обе стороны. Нажатие
энкодера работает как обычная клавиша.

Поддерживаются обычные клавиши, модификаторы, мультимедиа/система, MO/TO/TG/DF/LM,
Caps Word, Repeat, Alt Repeat, Grave Escape и Tri Layer. Lower/Upper используют 1/2 и вместе
включают 3. Обычные MO(1)/MO(2) Tri Layer не активируют. Добавления кандидата —
в [статусе](STATUS.md).

В списке Vial могут быть действия, которые прошивка не поддерживает. Mod Tap и
Layer Tap отправляют только символ клавиши; удержание они не распознают.
One Shot, Mouse Keys, Tap Dance, Combos и Key Overrides не поддерживаются.
Импорт раскладки не добавляет эти возможности.

Есть 16 слотов макросов с общим объёмом 8192 байта. Создавайте макросы в
редакторе Vial. Для каждого нажатия добавляйте отпускание клавиши. Макрос
исполняется самой клавиатурой, фоновая программа не нужна. Перед заменой
прошивки экспортируйте раскладку Vial, чтобы потом восстановить её. Этот файл
не заменяет личную ROM-копию для восстановления, которую установщик делает
при установке.

Чтобы разблокировать Vial, удерживайте физические Escape и левый Control
вместе три секунды. Прошивка также освободит клавиши, которые считает
зажатыми. После настройки заблокируйте Vial снова.

Подсветка: постоянный цвет, дыхание, цветовой и горизонтальный циклы, VialRGB
Direct и Solid Reactive Simple в кандидате RC6 (эффект Vial 31). Нажатие зажигает
светодиод под этой клавишей и запускает отдельное затухание. Подсветка гаснет,
даже если клавиша остаётся нажатой; отпускание не ускоряет затухание. Когда
клавиши не нажаты, все светодиоды чёрные. Подсветка гаснет под каждой клавишей;
световая волна по клавиатуре не идёт.

Значение скорости задаёт время затухания: 0–63 — 2048 мс, 64–127 — 1024 мс,
128–191 — 512 мс, 192–255 — 256 мс. Прошивка обновляет затухание каждые 16 мс.
Смена режима, выключение подсветки, сон клавиатуры или повторная загрузка
настроек очищают историю нажатий. По словам владельца, реактивная подсветка
на установленном кандидате работает нормально. Это наблюдение на устройстве,
а не новый автоматический тест или точное сравнение с заводским эффектом.

Цвет для каждого светодиода в режиме Direct хранится только в оперативной
памяти и теряется после перезапуска. Общие настройки подсветки сохраняются.
Новая компактная кривая может немного округлять отображаемую яркость, но не
меняет значения HSV, которые передаются и сохраняются. В [бюджете памяти](RESOURCE-BUDGET.md)
и [статусе](STATUS.md) приведены замеры и результаты проверок. Если действие
видно в Vial, это ещё не значит, что прошивка его поддерживает.
