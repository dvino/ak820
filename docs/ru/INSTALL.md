# Установка

В beta.5 доступны пакеты с исходным кодом Python для Windows и Linux x86_64.
В них входят сценарии установщика и все десять профилей прошивки. Графического
приложения в пакетах нет. Требуется Python 3.10 или новее: в Windows
используйте команду `python`, в Linux — `python3`.

Установщик предназначен только для проводной AJAZZ AK820 с поддерживаемыми
контроллером VS11K28A и ревизией платы. V2, Pro и Max не поддерживаются.
Названия модели и USB ID `320F:505B` недостаточно для проверки совместимости.

## Загрузка и проверка пакета

На [странице beta.5](https://github.com/dvino/ak820/releases/tag/v0.6.0-beta.5)
скачайте архив и соответствующий файл `.sha256`:

- Windows: `AK820-Windows.zip` и `AK820-Windows.zip.sha256`.
- Linux x86_64: `AK820-Linux-x86_64.tar.gz` и файл с таким же именем и расширением `.sha256`.

В Windows сравните архив с контрольной суммой в PowerShell:

```powershell
$expected = (Get-Content .\AK820-Windows.zip.sha256 -Raw).Trim().Split()[0]
$actual = (Get-FileHash .\AK820-Windows.zip -Algorithm SHA256).Hash
if ($actual -ne $expected) { throw 'SHA256 mismatch; do not extract this package.' }
```

В Linux выполните команду в папке, где находятся оба файла:

```sh
sha256sum -c AK820-Linux-x86_64.tar.gz.sha256
```

Если сумма не совпала, не распаковывайте архив. Скачайте оба файла ещё раз.

## Windows

Установите Python 3.10 или новее и проверьте, что доступна команда `python`.
Распакуйте ZIP, откройте папку `AK820-Python` и создайте локальное окружение:

```powershell
cd AK820-Python
.\AK820.cmd setup
.\AK820.cmd verify
```

Сценарий `AK820.cmd` будет использовать это окружение автоматически. Например,
`.\AK820.cmd diagnose` перечисляет подходящие USB-интерфейсы, не открывая их.

## Linux

Установите Python 3.10 или новее, `python3-venv`, компилятор C, заголовки
разработки Python и файлы разработки `libudev`. В Debian и Ubuntu это пакеты
`python3`, `python3-venv`, `python3-dev`, `build-essential` и `libudev-dev`.

Распакуйте архив, перейдите в `AK820-Python` и создайте окружение:

```sh
tar -xzf AK820-Linux-x86_64.tar.gz
cd AK820-Python
./AK820.sh setup
./AK820.sh verify
```

Для доступа к клавиатуре нужны обычные права пользователя. Если доступа нет,
из графического терминала выполните `./AK820.sh udev --install`. Если новые
права не вступили в силу, выйдите из системы и войдите снова. Не запускайте
установщик через `sudo`.

## Подготовка и установка

Команда `verify` проверяет файлы профилей и разрешение на выпуск без доступа
к USB. Чтобы проверить другой профиль, добавьте `--profile` перед командой:
например, `./AK820.sh --profile game verify` в Linux или
`.\AK820.cmd --profile game verify` в Windows. По умолчанию выбран `main`.
Все десять профилей и их отличия описаны в
[`docs/profiles/README.md`](profiles/README.md).

Перед установкой закройте OEM-конфигуратор, подключите одну поддерживаемую
клавиатуру, подготовьте запасной ввод и стабильное питание. Прочитайте раздел
[Резервное копирование и восстановление настроек](SETTINGS-BACKUP.md).
Команда `prepare` создаёт план установки, не записывая данные в клавиатуру.
Команда `install` предназначена для установки со штатной OEM-прошивки.
Она проверяет устройство, сохраняет свежую копию OEM-прошивки и показывает
точный образ. Перед записью нужно ввести `yes`. После перезапуска установщик проверяет образ и ввод с
клавиатуры. Сохраните всю папку сеанса, включая `permanent-session`, отдельно
и в закрытом месте. При ошибке остановитесь: не повторяйте запись, не
сбрасывайте клавиатуру и не запускайте восстановление вслепую.

Для обновления поддерживаемой установки QMK/Vial используйте
`update --session OEM_DIR --backup-dir NEW_BACKUP_DIR`. Укажите исходный сеанс
восстановления OEM и новую папку для бэкапа. Сценарий сохраняет текущие настройки,
проверяет их перенос и просит заново удерживать Esc + левый Control три секунды.
Перед восстановлением настроек после обновления потребуется второе физическое
подтверждение.

## OEM-восстановление

Для поддерживаемого восстановления используйте `recover --session OEM_DIR`,
только если клавиатура уже находится в загрузчике. Для восстановления настроек
выберите сохранённый сеанс и выполните команду `restore`, описанную в разделе
[Резервное копирование и восстановление настроек](SETTINGS-BACKUP.md).
Восстанавливайте настройки только после подтверждения совместимости точных
исходного и целевого образов.

## Каталог для компаньона

Архив `AK820-Beta5-Catalog.zip` содержит прошивки и данные для интеграции с
компаньоном, но не настольное приложение. Интеграция будет подготовлена
отдельно.
