# Установка и восстановление

Эти пакеты предназначены для проводной AJAZZ AK820 с контроллером VS11K28A и
соответствующей ревизией платы. V2, Pro и Max не поддерживаются. Названия модели
и USB `320F:505B` недостаточно, чтобы подтвердить совместимость. Подготовьте
корректную OEM-сессию восстановления и отдельную копию настроек.

## Загрузка и проверка пакета

Откройте страницу [Releases](https://github.com/dvino/ak820/releases) и
скачайте пакет и соответствующий ему файл `.sha256`:

- Windows: `AK820-Windows.zip` и `AK820-Windows.zip.sha256`.
- Linux x86_64: `AK820-Linux-x86_64.tar.gz` и
  `AK820-Linux-x86_64.tar.gz.sha256`.

В Windows сравните архив с контрольной суммой в PowerShell:

```powershell
$expected = (Get-Content .\AK820-Windows.zip.sha256 -Raw).Trim().Split()[0]
$actual = (Get-FileHash .\AK820-Windows.zip -Algorithm SHA256).Hash
if ($actual -ne $expected) { throw 'SHA256 mismatch; do not extract this package.' }
```

В Linux выполните команду в папке, где находятся оба скачанных файла:

```sh
sha256sum -c AK820-Linux-x86_64.tar.gz.sha256
```

Если контрольная сумма не совпала, не распаковывайте и не запускайте пакет.
Скачайте оба файла ещё раз.

## Windows

Распакуйте весь ZIP и сохраните папки рядом. Запустите
`AK820-Windows/AK820/AK820.exe`. Устанавливать Python не нужно. Командная
утилита находится в `AK820-Windows/AK820-cli/AK820-cli.exe`.

## Linux

Отдельный пакет предназначен для Linux x86_64 с glibc 2.35 или новее,
например Ubuntu 22.04. Python и Tk включены. Нужны `libudev1`, графический
сеанс с поддержкой X11 или XWayland, а также обычный доступ `udev` к устройству
через hidraw.

После проверки суммы распакуйте архив и запустите GUI:

```sh
tar -xzf AK820-Linux-x86_64.tar.gz
cd AK820-Linux-x86_64
./AK820/AK820
```

Если приложению не удаётся открыть клавиатуру, установите правило доступа из
обычного терминала рабочего стола:

```sh
./AK820-cli/AK820-cli udev --install
```

Эта команда использует `sudo` только для установки и применения правила.
Запускайте GUI от обычного пользователя, без `sudo`.

## Копия настроек и обновление прошивки

Перед изменением прошивки прочитайте [Сохранение и восстановление
настроек](SETTINGS-BACKUP.md). В GUI выберите OEM-сессию и новую папку для
резервной копии, затем нажмите Update. Сначала подготовьте запасной способ
ввода и стабильное питание. Установщик показывает точное обновление; свежее
физическое удержание Esc + левого Ctrl в течение трёх секунд подтверждает его.
Установщик запросит разблокировку, войдёт в загрузчик, один раз запишет образ
и проверит его. Затем он запросит второе новое удержание перед восстановлением
и проверкой сохранённых настроек. Оба удержания выполняются внутри установщика.
Не нужны ввод `yes`, отдельное приложение Vial или ручной переход в
Bootloader. Если показано не то обновление, отмените действие до стирания.

При тайм-ауте, ошибке хранилища или неверном чтении остановитесь. Не повторяйте
операцию, не сбрасывайте клавиатуру и не запускайте восстановление вслепую.
В [руководстве по настройкам](SETTINGS-BACKUP.md) описаны состав копии и
перенос старых копий в прошивку с Combo.

## OEM-восстановление

OEM-сессия содержит исходные данные прошивки, нужные для сборки и проверки
поддерживаемого образа. Храните её отдельно от копии настроек и не публикуйте.
Для восстановления из уже видимого загрузчика используйте команду CLI
`recover --session OEM_DIR`. Если приложение не отвечает и загрузчик недоступен,
остановитесь и обратитесь за помощью; не повторяйте стирание.

## Исходный установщик

Для установки выпуска обычно используются готовые пакеты выше. Чтобы запускать
исходный установщик или собирать прошивку, следуйте разделу [Сборка](../BUILD.md).
Исходным программам нужен Python 3.10 или новее; для сборки прошивки требуется
Linux или WSL с закреплённым набором инструментов.
