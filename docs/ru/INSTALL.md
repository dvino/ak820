# Установка и восстановление

Эти инструкции описывают пакеты beta.2; состояние публикации указано в [разделе «Состояние проекта»](STATUS.md).

Пакеты предназначены только для проводной AJAZZ AK820 с контроллером VS11K28A
и соответствующей ревизией платы. V2, Pro и Max не поддерживаются. Названия
модели и USB ID `320F:505B` недостаточно, чтобы подтвердить совместимость. При
первой установке создаётся OEM-сессия восстановления. Храните её отдельно от
последующих копий настроек и не публикуйте.

Автономные инструкции входят в каждый пакет: `AK820/_internal/docs/` — английские, `AK820/_internal/docs/ru/` — русские. Для выбора состава откройте `profiles/README.md` в каталоге нужного языка.

## Выбор профиля

Установщик предлагает десять профилей прошивки. По умолчанию выбран `main`.
Выберите профиль до начала операции: рядом показаны его назначение и отличия
от `main`. Пока выполняются проверка пакета, подготовка, подтверждение и
установка, выбор заблокирован. Сам выбор профиля не записывает данные в
клавиатуру.

| Профиль | Что добавлено или изменено |
| --- | --- |
| `main` | Key Overrides, выбор сохранённых Vial-макросов через Leader, временные Dynamic Macros и прямое управление VialRGB. |
| `game` | Добавляет отчёты NKRO, переключатель NKRO и блокировку Win/Command; сохраняет Key Overrides, Dynamic Macros и прямое управление подсветкой; убирает Leader. |
| `mmo` | Добавляет NKRO, блокировку Win/Command и восемь действий Tap Dance вместо Key Overrides; сохраняет Dynamic Macros и прямое управление подсветкой; убирает Leader. |
| `typing` | Добавляет Auto Shift и Space Cadet; сохраняет Key Overrides, Leader и Dynamic Macros; убирает прямое управление подсветкой. |
| `code` | Добавляет Space Cadet и Grave Escape; сохраняет Key Overrides, Leader и Dynamic Macros; убирает прямое управление подсветкой. |
| `pointer` | Добавляет Mouse Keys для управления указателем, прокрутки и кнопок мыши; сохраняет Key Overrides, Leader и Dynamic Macros; убирает прямое управление подсветкой. |
| `onehand` | Добавляет Mouse Keys и Tap Dance; сохраняет Leader и Dynamic Macros; убирает Key Overrides и прямое управление подсветкой. |
| `creative` | Добавляет Tap Dance; сохраняет Leader, Dynamic Macros и прямое управление подсветкой; убирает Key Overrides. |
| `shortcuts` | Добавляет Tap Dance; сохраняет Key Overrides и Leader; убирает Dynamic Macros и прямое управление подсветкой. |
| `multios` | Добавляет режим Mac/PC для Alt/GUI и перестановку Ctrl/GUI; сохраняет Key Overrides, Leader и Dynamic Macros; убирает прямое управление подсветкой. |

Во всех профилях есть шесть слоёв, 16 сохранённых макросов Vial, восемь
комбинаций клавиш, QMK Settings для поддерживаемых временных параметров,
One Shot, общие функции удержания и мультимедиа, встроенные эффекты RGB и
индикатор ОС, которым управляет хост. В `main` также включены Key Overrides
и прямое управление VialRGB. Direct нужен совместимому приложению для
управления отдельными светодиодами; встроенные эффекты доступны во всех
профилях. Подробности и ограничения приведены в [описаниях профилей](profiles/README.md).

Чтобы сменить установленный профиль, подготовьте обновление на выбранный
целевой профиль и создайте резервную копию настроек. Установщик проверяет
совместимость по точным исходному и целевому образам и остановится до записи,
если переход не поддерживается. В CLI профиль задаётся параметром
`--profile`, например `AK820-cli --profile game verify`. Команда `verify`
проверяет файлы пакета и не обращается к клавиатуре.

## Загрузка и проверка пакета

Откройте [страницу beta.2](https://github.com/dvino/ak820/releases/tag/v0.6.0-beta.2)
и скачайте пакет и соответствующий ему файл контрольной суммы:

- Установщик Windows: [AK820-Windows.zip](https://github.com/dvino/ak820/releases/download/v0.6.0-beta.2/AK820-Windows.zip) и [AK820-Windows.zip.sha256](https://github.com/dvino/ak820/releases/download/v0.6.0-beta.2/AK820-Windows.zip.sha256).
- Установщик Linux x86_64: [AK820-Linux-x86_64.tar.gz](https://github.com/dvino/ak820/releases/download/v0.6.0-beta.2/AK820-Linux-x86_64.tar.gz) и [AK820-Linux-x86_64.tar.gz.sha256](https://github.com/dvino/ak820/releases/download/v0.6.0-beta.2/AK820-Linux-x86_64.tar.gz.sha256).
- Каталог прошивок и компаньона: [AK820-Beta2-Catalog.zip](https://github.com/dvino/ak820/releases/download/v0.6.0-beta.2/AK820-Beta2-Catalog.zip) и [AK820-Beta2-Catalog.zip.sha256](https://github.com/dvino/ak820/releases/download/v0.6.0-beta.2/AK820-Beta2-Catalog.zip.sha256).

В Windows сравните архив с контрольной суммой в PowerShell. Для установщика
выполните:

```powershell
$expected = (Get-Content .\AK820-Windows.zip.sha256 -Raw).Trim().Split()[0]
$actual = (Get-FileHash .\AK820-Windows.zip -Algorithm SHA256).Hash
if ($actual -ne $expected) { throw 'SHA256 mismatch; do not extract this package.' }
```

Для архива Linux или каталога используйте соответствующее имя файла
`.sha256`. В Linux выполните команду в папке, где находятся оба файла,
например:

```sh
sha256sum -c AK820-Linux-x86_64.tar.gz.sha256
```

Если контрольная сумма не совпала, не распаковывайте и не запускайте архив.
Скачайте оба файла ещё раз.

## Windows

Распакуйте весь ZIP и сохраните папки рядом. Запустите
`AK820-Windows/AK820/AK820.exe`. Устанавливать Python не нужно. Командная
утилита находится в `AK820-Windows/AK820-cli/AK820-cli.exe`.

## Linux

Отдельный пакет предназначен для Linux x86_64 с glibc 2.35 или новее,
например Ubuntu 22.04. Python и Tk включены. Нужны `libudev1`, графический
сеанс с поддержкой X11 или XWayland и обычный доступ `udev` к устройству через
hidraw.

После проверки суммы распакуйте архив и запустите GUI:

```sh
tar -xzf AK820-Linux-x86_64.tar.gz
cd AK820-Linux-x86_64
./AK820/AK820
```

Если приложению не удаётся открыть клавиатуру, установите правило доступа из
обычного терминала рабочего стола:

```sh
./AK820-cli/AK820-cli udev --install
```

Команда использует `sudo` только для установки и применения правила.
Запускайте GUI от обычного пользователя, без `sudo`.

## Каталог прошивок и компаньона

В архиве каталога находятся образы прошивок и данные для интеграции
компаньона; запускаемого настольного приложения там нет. JSON-файлы описывают
выбор профиля, возможности точных образов и справку по модулям. Пути
`guide.en` и `guide.ru` в описаниях модулей отсчитываются от каталога `web/`
репозитория. Для их разрешения используйте базовый адрес
`https://github.com/dvino/ak820/blob/v0.6.0-beta.2/web/`. Чтобы справка была
доступна без сети, включите эти руководства в пакет компаньона. Перед
интеграцией прочитайте [контракты прошивки](https://github.com/dvino/ak820/blob/v0.6.0-beta.2/web/docs/ru/FIRMWARE-HANDOFF.md).

## Первая установка из OEM-прошивки

Если на клавиатуре ещё заводская OEM-прошивка, заранее сохранённая сессия
восстановления не нужна. Закройте OEM-конфигуратор и подключите только одну
поддерживаемую клавиатуру. Подготовьте запасной способ ввода и стабильное
питание.

В GUI откройте **Другие действия — установка из OEM и восстановление** и
выберите **Установить из OEM**. Подтвердите чтение полной исходной прошивки.
Установщик проверит копию, подготовит обновление и покажет образ перед
запросом подтверждения записи. Следуйте подсказкам, включая проверку печати
после перезапуска. При ошибке остановитесь и не повторяйте запись вслепую.

Сохраните всю папку сеанса, указанную в журнале. В её подпапке
`permanent-session` находятся `images.json`, `before-full-rom.bin` и
`restore-native.bin`; для следующих обновлений и восстановления выбирайте
именно эту подпапку как OEM-сессию. Эти личные файлы считываются с клавиатуры,
а не скачиваются с релизом. Кнопка **Сохранить резервную копию OEM** в том же
разделе создаёт сессию восстановления без установки прошивки.

## Копия настроек и обновление прошивки

Перед изменением прошивки прочитайте [руководство по сохранению и
восстановлению настроек](SETTINGS-BACKUP.md). В GUI выберите OEM-сессию и новую
папку для резервной копии, затем нажмите Update. Сначала подготовьте запасной
способ ввода и стабильное питание. Установщик покажет точное обновление;
свежее физическое удержание Esc + левого Control в течение трёх секунд
подтверждает его. Установщик запросит разблокировку, войдёт в загрузчик,
один раз запишет образ и проверит его. Затем он запросит второе новое
удержание перед восстановлением и проверкой сохранённых настроек. Оба
удержания выполняются внутри установщика. Не нужны ввод `yes`, отдельное
приложение Vial или ручной переход в Bootloader. Если показано не то
обновление, отмените действие до стирания.

При тайм-ауте, ошибке хранилища или неверном чтении остановитесь. Не
повторяйте операцию, не сбрасывайте клавиатуру и не запускайте восстановление
вслепую. В [руководстве по настройкам](SETTINGS-BACKUP.md) описаны состав
копии и перенос старых копий в прошивку с Combo.

## OEM-восстановление

OEM-сессия содержит исходные данные прошивки, нужные для сборки и проверки
поддерживаемого образа. Храните её отдельно от копии настроек и не публикуйте.
Для восстановления из уже видимого загрузчика используйте команду CLI
`recover --session OEM_DIR`. Если приложение не отвечает и загрузчик недоступен,
остановитесь и обратитесь за помощью; не повторяйте стирание.
