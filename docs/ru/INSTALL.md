# Установка и восстановление

Используйте полный выпуск с проводной AJAZZ AK820 / VS11K28A. Установщик также
проверяет прошивку в клавиатуре: одного названия модели и USB ID недостаточно,
чтобы определить поддерживаемую версию. Если версия не поддерживается,
установщик остановится до стирания. В [статусе](STATUS.md) указаны проверенная
сборка и результаты испытаний на клавиатуре.

Подготовьте другую клавиатуру или экранный ввод операционной системы: в родном
загрузчике AK820 не печатает. Закройте другие конфигураторы. Подключите одну
поддерживаемую клавиатуру и не вынимайте кабель до завершения установки и проверок.

До сброса и стирания установщик читает все 65 536 байт ROM клавиатуры и сохраняет
точную личную копию для восстановления. Настройки переносятся, только если новая
прошивка их поддерживает. Если назначение клавиши нельзя перенести или макрос
слишком велик, подготовка остановится, а данные не будут молча потеряны. Неполная
копия может помочь при поиске ошибки, но полной копией не считается. Скопируйте
папку восстановления в отдельное место. Не используйте чужую копию и не публикуйте
личные настройки.

ROM производителя не входит в комплект. Установщик сравнивает вашу копию с
известными признаками загрузчика, защищённой области и версии заводской прошивки,
а затем создаёт личные файлы сравнения в папке восстановления. Эта проверка
определяет поддерживаемую версию, но не доказывает совместимость других клавиатур
с таким же названием или USB ID.

## Обновление RC6 на клавиатуре владельца

Кнопка GUI `Обновить прошивку` предназначена только для точного
кандидата и личной сессии, проверенных в этой работе. Это не общий способ
обновления других клавиатур и образов. Перед использованием должны пройти
ревью программы и проверка готового EXE; состояние — в [статусе](STATUS.md).

Выберите подготовленную личную сессию. GUI прочитает и сохранит полный ROM,
сравнит его с зафиксированным состоянием после сбоя и остановится при отличиях.
Образ сохраняет настройки до неудачного теста энкодера, включая исходное
действие по часовой стрелке, и убирает незавершённую запись этого теста из
журнала. Программа покажет хеш образа и запросит согласие перед записью.

Встроенный путь обновления прошёл ревью и установку у владельца. Нажмите «Обновить прошивку»,
затем по приглашению удерживайте физические Esc + левый Ctrl вместе три секунды.
Это новое удержание подтверждает показанное обновление. Вводить `yes` или
`ready`, открывать Vial и вручную выбирать Bootloader не нужно. Установщик сам
запрашивает разблокировку, проверяет её завершение, отправляет одну команду
перехода и ждёт загрузчик. До стирания можно отменить действие. При ошибке
команды или перехода программа остановится без повтора, сброса и восстановления.
После одной записи программа проверит запуск и полное чтение ROM. Печать
и отключение питания в эти проверки не входят.

На русской системе GUI запускается по-русски, на любой другой — по-английски.
Кнопка RU / EN меняет язык интерфейса.

## Командная строка из исходников

Нужен Python 3.10+. WSL требуется для сборки, но не для установки готового образа.

| Действие | Linux | Windows |
| --- | --- | --- |
| Проверка без USB | `./AK820.sh verify` | `.\AK820.cmd verify` |
| Зависимости | `./AK820.sh setup` | `.\AK820.cmd setup` |
| Только перечисление устройств | `./AK820.sh` | `.\AK820.cmd` |
| Копия и постоянная установка | `./AK820.sh install` | `.\AK820.cmd install` |
| Явный trial | `./AK820.sh install --trial` | `.\AK820.cmd install --trial` |
| Восстановление из видимого loader | `./AK820.sh recover --session PATH` | `.\AK820.cmd recover --session PATH` |

Пути с пробелами заключайте в кавычки. Чтобы начать подготовку, введите `y`;
Enter отменяет действие. Перед записью установщик покажет файл прошивки и папку
восстановления, а затем попросит ввести точное слово `yes` строчными буквами.
Он спрашивает оба подтверждения, пока клавиатура ещё печатает. При отмене сброса
и стирания не будет.

Постоянный режим сохраняет метку, по которой запускается приложение. Пробный
режим стирает её при запуске, поэтому после сброса или отключения клавиатура
возвращается в загрузчик. Пробный режим не предназначен для обычной работы.
Успешной передачи файла или совпадения checksum недостаточно: установщик также
проверяет, что клавиатура работает, просит вас напечатать текст и читает обратно
приложение, защищённые области и начальные настройки.

## Восстановление

Если постоянная прошивка отвечает, разблокируйте Vial и выберите Bootloader.
Это очистит метку приложения и перезапустит клавиатуру в родном загрузчике.
Простое отключение постоянной прошивки не запускает восстановление. Выполните
`recover --session PATH`, указав свою полную папку восстановления. Команда не
перезапускает работающее приложение и не повторяет неудачное стирание. Если
приложение не отвечает и загрузчик недоступен, остановитесь: программное
восстановление в такой ситуации не гарантировано.

Windows GUI и командная строка собраны в отдельные папки. Используйте целиком
`dist/AK820-sdcc46-breathing-20261023/AK820/` или
`dist/AK820-sdcc46-breathing-20261023/AK820-cli/`: одного EXE недостаточно. Для этих приложений
на компьютере не нужен Python. Исходная версия установщика требует Python 3.10+.
Сборка и проверки без клавиатуры описаны в [статусе](STATUS.md). Публичной
загрузки пока нет.
