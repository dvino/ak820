# Профили прошивки

Все функции одновременно не помещаются в память контроллера. Поэтому прошивка собрана из модулей: профиль задаёт набор доступных функций. `main` выбран по умолчанию. В остальных профилях часть его модулей заменена функциями для конкретных задач.

Выбор профиля меняет прошивку. Обычная смена слоя в Vial не добавляет отсутствующий модуль. Установщик для Windows и Linux позволяет выбрать профиль; доступность установки зависит от проверки и допуска точного образа. Приложение-компаньон AK Configurator ещё разрабатывается. Порядок действий описан в [установке](../INSTALL.md), состояние выпуска — в [статусе](../STATUS.md).

| [typing](typing.md) | Auto Shift, Shift/скобки через Space Cadet и Tap Dance для нескольких действий на клавише. Встроенные RGB-эффекты сохраняются, Direct уступает место функциям ввода. |
| [code](code.md) | Space Cadet для скобок, Grave Escape для совмещённой Esc/обратной кавычки и Tap Dance для нескольких действий. Автоматический Shift не включён; Direct уступает место этим функциям. |

## Общие функции

Во всех десяти профилях доступны:

- Шесть редактируемых слоёв и действия энкодера для каждого слоя.
- 16 сохраняемых макросов Vial и восемь Combo из двух клавиш.
- Mod-Tap и Layer-Tap, One Shot, Caps Word, Repeat и Alt Repeat, Tri Layer.
- Мультимедийные и системные клавиши, встроенные эффекты RGB.
- QMK Settings для поддерживаемых параметров времени.
- Индикаторы C (Caps Lock), W (активный слой выше нулевого) и управление OS от компьютера.

[Каталог функций](../FEATURES.md) описывает настройку и ограничения. NKRO, блокировка GUI, Grave Escape, Space Cadet и Direct зависят от выбранного профиля.

## Ограничения модулей

Tap Dance содержит восемь записей. Их четыре действия принимают базовую клавишу, модификатор или клавишу с модификаторами; слои, макросы, мышь и вложенные специальные действия не поддерживаются. Key Overrides содержит восемь замен. Leader выбирает один из 16 сохранённых макросов Vial.

Две динамические записи по 16 завершённых нажатий хранятся в оперативной памяти и теряются после перезапуска. Это отдельные записи; 16 макросов Vial сохраняются в памяти клавиатуры.

Индикатор OS не определяет операционную систему или раскладку сам. Совместимая программа задаёт состояние и регулярно продлевает его; без обновления в течение трёх секунд действует обычное состояние индикатора. В `multios` оно зависит от временного режима Mac/PC, в остальных профилях индикатор выключен.
