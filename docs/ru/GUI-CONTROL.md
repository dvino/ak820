# Клавиши Win/GUI

Временно блокируйте или восстанавливайте передачу модификатора GUI.

После перезапуска блокировка выключена.


Блокировка GUI доступна в профилях `game` и `mmo`; в `main` её нет. При
включённой блокировке W плавно меняет яркость с циклом 2000 мс. При выключении
блокировки пульсация прекращается. Активный или начальный слой выше 0 имеет
приоритет: W горит постоянно. Индикаторы C и OS работают независимо.
Низкоуровневый CLI сохраняет старые имена профилей `full-*` для повторения
прежних сборок.

| Код | Действие |
| --- | --- |
| `GU_OFF` | Отключить левую и правую клавиши Win/GUI в отчётах клавиатуры. |
| `GU_ON` | Снова включить обе клавиши. |
| `GU_TOGG` | Переключить состояние. |

GUI — клавиша Windows в Windows, обычно Super/Meta в Linux. Состояние меняется
при нажатии управляющей клавиши и действует до перезапуска. После перезапуска
GUI снова включён. Записи во флеш-память нет.

Эти три управляющие клавиши сохраняют ожидающие модификаторы One Shot
и историю Repeat.

Отключение сразу убирает GUI из отчёта, сохраняя остальные клавиши и
модификаторы. Фильтр действует на физические клавиши, сочетания с модификаторами,
One Shot и программно созданные нажатия. Внутренний учёт удержания сохраняется.
Если включить GUI, пока соответствующая клавиша ещё удерживается, её нажатие
сразу вернётся в отчёт. При необходимости сначала отпустите её.

Удерживаемая Win/GUI по-прежнему считается модификатором для Auto Shift:
нажатия проходят без его задержки даже при отключённом выводе GUI. Динамические
макросы тоже сохраняют записанный GUI; этот фильтр определяет, отправлять ли его.

Сброс нажатий, переключение NKRO и очистка при выходе из сна отпускают клавиши,
но сохраняют выбранное состояние GUI. Блокировка GUI не включает остальные
действия Magic или сохранение QMK Settings.

## Перестановка Ctrl/GUI

Меняйте местами Ctrl и GUI слева и справа до перезапуска.


Пакет `system` добавляет три кода Vial для перестановки Ctrl/GUI.
Низкоуровневый CLI сохраняет старое имя `full-ctrl-gui` для повторения сборок:

| Код | Действие |
| --- | --- |
| `CG_SWAP` (`0x701b`) | Меняет левый Ctrl с левым GUI, а правый Ctrl — с правым GUI. |
| `CG_NORM` (`0x701c`) | Возвращает обычное соответствие. |
| `CG_TOGG` (`0x701d`) | Переключает обычное и изменённое соответствие. |

Преобразование применяется к выводу до фильтра GUI. Внутренние владельцы
модификаторов сохраняются, поэтому изменение соответствия не сбрасывает
удерживаемые модификаторы. Состояние действует до перезапуска и не сохраняется.
Постоянные параметры Magic не добавляются.
