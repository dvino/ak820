# Индикаторы C и W

В прошивке разработки включены два отдельных выхода индикаторов:

- **C** показывает Caps Lock из LED-отчёта хоста. Само нажатие Caps не меняет
  светодиод: настоящее состояние сообщает компьютер. Caps Word сам по себе
  его не включает.
- **W** показывает активность слоя выше слоя 0. Учитываются удерживаемые,
  переключаемые и основные слои, включая Lower/Upper/Adjust. Возврат к слою 0
  гасит выход. Блокировку клавиш Windows он не показывает.

Индикаторы не зависят от режима, яркости и включения подсветки клавиш.
До настройки USB и во время USB suspend оба выхода погашены. После настройки
или возобновления следующий проход основного цикла вычисляет их заново.
Для этих выходов ничего не сохраняется в память; назначение Caps остаётся прежним.

## Реализация и проверки

Выходы взяты из [разбора потока данных OEM](../../audits/rc6/oem-indicator-dataflow-review-20261024.md):
слот 71, компонент 1 для бита Caps, и слот 79, компонент 1 для второго состояния.
В прошивке разработки второму выходу назначен дополнительный слой по правилам
проекта. Эти слоты не входят в карту 82 светодиодов клавиш. Остальные компоненты
этих слотов сохраняются.

Обновление выполняется в основном цикле. На время записи двух слотов
сохраняется и затем восстанавливается прежний бит разрешения прерывания сканирования;
USB-прерывания остаются разрешёнными. Постоянная память не используется.
Кандидат добавляет 78 заполненных байт CODE без изменения XRAM. Точная сборка
и результаты проверок записаны в [Статусе](STATUS.md).

CPU-модель связанного кода проверяет биты LED-отчёта, производственные функции
слоёв, основные слои и путь Tri Layer, модели состояния USB, контрольные байты
RGB и восстановление бита прерывания. Модель состояния не проверяет физический
сброс USB или видимые светодиоды.

Физическое подключение C/W и видимая работа ещё не проверены. Это кандидат
из исходников, а не доказательство установки. Прежняя прошивка в отслеживаемом
комплекте установщика этой реализации не содержит.
