# QMK и Vial для AJAZZ AK820

![Баннер прошивки QMK / Vial для AJAZZ AK820](../images/banner.webp)

Этот проект переносит QMK и Vial на **проводную AJAZZ AK820 с контроллером
VS11K28A / CH555-like 8051**, USB `320F:505B`. AK820 V2, Pro и Max устроены
иначе и не поддерживаются.

Настройте клавиши, слои, энкодер и макросы в Vial. После этого клавиатура
работает без фоновой программы на компьютере. Порт сохраняет исходный
загрузчик и настройки в самой клавиатуре.

Тестовый выпуск: [v0.6.0-alpha.1](https://github.com/dvino/ak820/releases/tag/v0.6.0-alpha.1). Перед установкой прочитайте примечания к релизу.

## Совместимость оборудования

| Модель | Микроконтроллер | Поддержка |
| --- | --- | --- |
| AJAZZ AK820 (проводная) | VS11K28A | Поддерживается |
| AJAZZ AK820 V2 | Другая платформа | Нет |
| AJAZZ AK820 Pro | Другая платформа | Нет |
| AJAZZ AK820 Max | Другая платформа | Нет |

USB VID:PID `320F:505B` — дополнительный признак, а не гарантия совместимости. Одного названия AK820 тоже недостаточно. Перед установкой прошивки сверьте контроллер и ревизию платы с фотографиями ниже.

Сохраните исходные файлы восстановления и прочитайте [инструкцию восстановления штатной прошивки](INSTALL.md#oem-восстановление).

## Возможности

- Шесть слоёв, на каждом можно отдельно назначить действия на вращение энкодера в обе стороны.
- Обычные клавиши, модификаторы, мультимедиа, системные команды и NKRO — ввод более шести клавиш одновременно.
- Шестнадцать макросов с общим хранилищем 8192 байта.
- Caps Word, Repeat, Alt Repeat, Grave Escape и Tri Layer.
- 82 RGB-светодиода: постоянный цвет, дыхание, цветовые циклы, VialRGB Direct и затухание подсветки нажатой клавиши.
- Сохранение раскладок, макросов и общих настроек RGB; физическая разблокировка Vial.
- В alpha есть компактные [Mod-Tap и Layer-Tap](TAP-HOLD.md). В старом комплекте репозитория они по-прежнему отправляют только обычную клавишу.
- В alpha есть [индикаторы C/W](INDICATORS.md): Caps Lock хоста и активный дополнительный слой.
- Исходный установщик локально сохраняет и восстанавливает поддерживаемые настройки, в том числе при обновлении прошивки. One Shot, Mouse Keys, Tap Dance, Combos и Key Overrides пока не поддерживаются.

## Начало работы

> Устанавливайте прошивку только на поддерживаемую проводную ревизию. С неподходящим образом клавиатура может перестать работать; совпадение USB ID не делает другую ревизию совместимой.

Перед использованием установщика прочитайте [установку и восстановление](INSTALL.md).

Команды резервного копирования и восстановления описаны в разделе
[Сохранение настроек](SETTINGS-BACKUP.md). Поддерживаются перечисленные там
точные проверенные образы SDCC 4.6; прежние проверенные Windows-приложения
собраны раньше и этой функции не содержат.

Для исходного установщика нужен Python 3.10+. Офлайн-проверка комплекта:
`./AK820.sh verify` в Linux или `.\AK820.cmd verify` в Windows.

[Настройка](CONFIGURATION.md) описывает Vial. Сборка прошивки использует
Linux/WSL, Python 3.11+ и закреплённый SDCC 4.6.0.

Прошивка из исходников — кандидат для разработки. Проверенный установщиком
выпуск — отдельный образ. Текущее состояние сборки и выпуска описано в
разделах [Сборка](BUILD.md) и [Статус](STATUS.md).
