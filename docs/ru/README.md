# QMK и Vial для AJAZZ AK820

![Баннер прошивки QMK / Vial для AJAZZ AK820](../images/banner.webp)

Этот проект переносит QMK и Vial на **проводную AJAZZ AK820 с контроллером
VS11K28A / CH555-like 8051**, USB `320F:505B`. AK820 V2, Pro и Max устроены
иначе и не поддерживаются.

Настройте клавиши, слои, энкодер и макросы в Vial. После этого клавиатура
работает без фоновой программы на компьютере. Порт сохраняет исходный
загрузчик и настройки в самой клавиатуре.

## Совместимость оборудования

| Модель | Микроконтроллер | Поддержка |
| --- | --- | --- |
| AJAZZ AK820 (проводная) | VS11K28A | Поддерживается |
| AJAZZ AK820 V2 | Другая платформа | Нет |
| AJAZZ AK820 Pro | Другая платформа | Нет |
| AJAZZ AK820 Max | Другая платформа | Нет |

USB VID:PID `320F:505B` — дополнительный признак, а не гарантия совместимости. Одного названия AK820 тоже недостаточно. Перед установкой прошивки сверьте контроллер и ревизию платы с фотографиями ниже.

Сохраните исходные файлы восстановления и прочитайте [инструкцию восстановления штатной прошивки](INSTALL.md#oem-восстановление).

## Возможности

- [Шесть редактируемых слоёв](CONFIGURATION.md#клавиши-слои-и-энкодер); на каждом отдельно назначаются действия энкодера в обе стороны.
- [Обычные клавиши, модификаторы, мультимедиа и системные команды](CONFIGURATION.md), включая выбор отчётов 6KRO и NKRO.
- [Шестнадцать макросов](CONFIGURATION.md#макросы) с общим хранилищем 8192 байта; они выполняются самой клавиатурой без фоновой программы.
- [**Caps Word**](CONFIGURATION.md#caps-word) позволяет набрать слово заглавными буквами, не удерживая Shift.
- [**One Shot**](CONFIGURATION.md#one-shot) для модификаторов и дополнительные действия при коротком нажатии клавиш Shift через [**Space Cadet**](CONFIGURATION.md#space-cadet).
- [**Repeat** и **Alt Repeat**](CONFIGURATION.md#repeat-и-alt-repeat) повторяют последнюю запомненную клавишу с модификаторами или выбирают парное действие, например стрелку в обратную сторону.
- [**Grave Escape**](CONFIGURATION.md#grave-escape) объединяет Escape и клавишу Grave на одной кнопке; действие зависит от удерживаемых модификаторов.
- [**Tri Layer**](CONFIGURATION.md#tri-layer) включает слой 3, когда одновременно активны слои 1 и 2.
- Восемь настраиваемых [комбинаций из двух клавиш](COMBOS.md): например, J + K отправляет Escape, а F + D — Ctrl+C при нажатии в пределах 40 мс.
- [Mod-Tap и Layer-Tap](TAP-HOLD.md): короткое нажатие отправляет клавишу, удержание включает модификатор или слой.
- [82 RGB-светодиода](CONFIGURATION.md#подсветка): постоянный цвет, дыхание, цветовые циклы, VialRGB Direct и отдельное затухание каждой нажатой клавиши.
- [Индикаторы C/W](INDICATORS.md): C показывает Caps Lock, W — активный дополнительный слой.
- Дополнительные функции разработки: блокировка GUI и временная перестановка левых/правых Ctrl и GUI; в опубликованной alpha.3 их нет.
- Сохранение [раскладок, макросов и общих настроек RGB](CONFIGURATION.md), [физическая разблокировка Vial](CONFIGURATION.md#разблокировка-vial) и [резервная копия настроек](SETTINGS-BACKUP.md), включая все восемь слотов Combo.

Примеры назначения и ограничения описаны в [руководстве по настройке](CONFIGURATION.md).
One Shot работает только с модификаторами, Space Cadet включает `SC_LSPO`,
`SC_RSPC` и `SC_SENT`. Компактные Mouse Keys, Auto Shift, Leader, управление GUI и
динамические макросы можно включить в выбранных профилях разработки; их нет в
опубликованном образе alpha.3. См. [Mouse Keys](COMPACT-MOUSE-KEYS.md),
[Auto Shift](COMPACT_AUTOSHIFT.md), [клавиши Win/GUI](GUI-CONTROL.md),
[Leader](COMPACT-LEADER.md), [динамические макросы](COMPACT-DYNAMIC-MACROS.md) и [профили сборки](BUILD-PROFILES.md).
Для каждой новой сборки профиля требуется [проверка стека и IRQ](RUNTIME-STACK.md)
до остальных регрессионных проверок.

## Начало работы

> Устанавливайте прошивку только на поддерживаемую проводную ревизию. С неподходящим образом клавиатура может перестать работать; совпадение USB ID не делает другую ревизию совместимой.

Скачайте пакет для Windows или Linux со страницы [Releases](https://github.com/dvino/ak820/releases), затем следуйте [инструкции установки и восстановления](INSTALL.md).

Команды резервного копирования и восстановления описаны в разделе
[Сохранение настроек](SETTINGS-BACKUP.md).

[Настройка](CONFIGURATION.md) описывает Vial. Чтобы собрать прошивку из
исходников, следуйте разделу [Сборка](BUILD.md). Сборка использует Linux/WSL,
Python 3.11+ и закреплённый SDCC 4.6.0.
