# QMK и Vial для AJAZZ AK820

Этот проект переносит QMK и Vial на **проводную AJAZZ AK820 с контроллером
VS11K28A / CH555-like 8051**, USB `320F:505B`. AK820 V2, Pro и Max устроены
иначе и не поддерживаются.

Настройте клавиши, слои, энкодер и макросы в Vial. После этого клавиатура
работает без фоновой программы на компьютере. Порт сохраняет исходный
загрузчик и настройки в самой клавиатуре.

**Готова новая локальная сборка RC6 с плавным Breathing на SDCC 4.6.**
Windows-пакет: `dist/AK820-sdcc46-breathing-20261023.zip`. Распакуйте всю
папку и запустите `AK820/AK820.exe`. Сборка прошла офлайн-проверки и
независимое ревью; на клавиатуру она ещё не установлена.

На клавиатуре владельца остаётся прежний RC6. На нём прошли запуск, чтение
после записи и автоматические проверки переназначения клавиш и энкодера;
владелец сообщил о нормальной реактивной подсветке. Общее обновление с
сохранением текущих настроек ещё не закончено. Direct Control не менялся.
Точные сборки, результаты и ограничения — в [статусе](STATUS.md).

## Возможности

- Шесть слоёв, на каждом можно отдельно назначить действия на вращение энкодера в обе стороны.
- Обычные клавиши, модификаторы, мультимедиа, системные команды и NKRO — ввод более шести клавиш одновременно.
- Шестнадцать макросов с общим хранилищем 8192 байта.
- Caps Word, Repeat, Alt Repeat, Grave Escape и Tri Layer.
- 82 RGB-светодиода: постоянный цвет, дыхание, цветовые циклы, VialRGB Direct и затухание подсветки нажатой клавиши.
- Сохранение раскладок, макросов и общих настроек RGB; физическая разблокировка Vial.
- Установщик, проверяющий полную личную копию и создающий приватные данные сравнения OEM в сессии восстановления.

По умолчанию установщик предлагает постоянный режим и отдельно спрашивает
подтверждение подготовки и записи. В нём нет ROM производителя, и он не
скачивает его из интернета. При первой установке из полной проверенной копии
клавиатуры создаются личные файлы для сравнения; отдельно загружать reference
не нужно. GUI и командная строка для Windows прошли локальные проверки без
клавиатуры; пути к проверенным приложениям указаны в статусе. Старый ZIP неактуален. Этот профиль не поддерживает
Tap-hold, One Shot, Mouse Keys, Tap Dance, Combos и Key Overrides.

## Начало работы

Перед записью прочитайте [установку и восстановление](INSTALL.md). Нужен
запасной способ ввода на время работы загрузчика. До сброса и стирания
установщик обязан создать полную копию вашей клавиатуры.

Для исходного установщика нужен Python 3.10+. Офлайн-проверка комплекта:
`./AK820.sh verify` в Linux или `.\AK820.cmd verify` в Windows.

[Настройка](CONFIGURATION.md) описывает Vial. Сборка прошивки использует
Linux/WSL, Python 3.11+ и закреплённый SDCC 4.6.0.
