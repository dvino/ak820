# Независимые ревью

Обновлено 2026-10-23. Ревью относится только к названным исходникам и артефакту.
Кандидат для разработки и выпуск установщика — разные образы. Эта страница
содержит ссылки на доказательства, а не машинное одобрение выпуска.

| Работа | Ревью и ограничения |
| --- | --- |
| Windows-пакет | [Ревью исходников](../../audits/rc6/windows-package-source-review-20261023.md): оба дерева приложений, точные файлы, подменённые сбои упаковки/запуска и workflow с ручным запуском. Запуск в Windows остаётся непроверенным. |
| Выбор компилятора и отчёты | [Ревью программы тестов](../../audits/rc6/regression-runner-review-20261023.md): выбранные инструменты доступны дочерним наборам, пропуски и ошибки запуска видны, образы проверяются на протяжении прогона. |
| Указатель XDATA в журнале | [Ревью пробы](../../audits/rc6/bounded-optimization-review-20261023.md): исходники/ABI, проверки на ПК и слинкованном коде, разница размеров и переносимые доказательства. Без выпуска и разрешения на устройство. |
| Инвентаризация, интеграция и документы | [Итоговое ревью](../../audits/rc6/roadmap-completion-review-20261023.md): независимая проверка кода, точное повторение JSON, закрытие замечаний и результат проверки документов/доказательств. |
| Протокол настроек и установщик | [Протокол](../../audits/rc6/host-settings-protocol-review-20261023.md), [копирование/восстановление](../../audits/rc6/host-settings-core-review-20261023.md) и [процесс установщика](../../audits/rc6/host-settings-workflow-review-20261023.md): синтетические офлайн-проверки, привязка образа и остановка при сбое. |
| Привязка выпуска установщика | [Точное решение](../../releases/rc6/reviews/independent-review.md): одобренные IHX/MAP/отчёт и 19 текущих host-файлов. Оно не одобряет кандидата с указателем или новый EXE. |

[Текущий статус](STATUS.md) содержит точные образы и уровни проверки.
[Манифест](../../audits/rc6/roadmap-qualification-20261023/manifest.json) сохраняет
начальные ошибки и итоговые результаты. Unit-, host- и CPU-тесты не доказывают
физическую работу USB/flash, ввод Windows, сохранность при потере питания и
предел всех путей стека. Прежние ревью остались в истории Git и отчётах по
артефактам; их хеши нельзя использовать для новой сборки.

Новому выпуску нужно отдельное независимое решение по точным IHX, MAP, отчёту
сборки и host-файлам. Сборка и ревью исходников не меняют файл одобрения
установщика. Публикация и запись в устройство — отдельные операции со своими
требованиями разрешения.
