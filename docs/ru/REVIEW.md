# Независимое ревью RC6

Дата: 2026-10-23. Проверены локальные исходники, документация и офлайн
доказательства. Это не разрешение прошивки и не подтверждение работы на устройстве.
Дополнительно проверено устранение зависимости offline release-builder от
приватного OEM snapshot.
Предыдущий образ прошёл независимое ревью без открытых ошибок. Запрошенное
изменение геометрии Vial проверено на новой связанной сборке и тесте определения
клавиатуры/GUI. Машинная привязка в английском оригинале указывает на этот образ;
предыдущая геометрическая база остаётся исторической.

Автор Alt Repeat и portable paths не рецензировал собственный Repeat: его проверил
автор RGB. Корневой рецензент сверил manifest сборки с исходным checkout. Автор
RGB/Flash получил независимое ревью диапазонов, выравнивания, сохранения соседних
байтов и порядка commit от рецензента firmware. Автор установщика получил
независимое ревью backup, factory migration, permanent/trial, GUI и инструкций;
он отдельно проверил корневой release builder и документацию.

Три замечания к runner закрыты: фиксированные каталоги мешали повторным запускам;
хеширование только после тестов допускало смешение сборок; описание RGB отклонения
не охватывало весь интервал 0–160. Теперь каталоги отдельные, IHX/MAP проверяются
до/после каждого набора и всего запуска. Два регрессионных теста проверяют повтор
и временную замену артефактов с последующим восстановлением.

Byte programming RC5 могло завершаться без сохранения metadata. RC6 читает текущую
страницу 64 байта, объединяет запрашиваемые биты и пишет через выровненный DPTR
block path. Соседи сохраняются при моделях overwrite и установки битов; readback
и commit-last остаются. Точная аппаратная причина отказа и электрическое поведение
исправления ещё не проверены. GUI теперь прямо говорит об отсутствии cold-boot
проверки. Публичный пакет не содержит OEM reference-образов; установщик проверяет
свежую полную копию устройства и автоматически создаёт приватные references сессии. Открытые ошибки не принимаются
как допустимые исключения.

Изменения геометрии Vial ограничены `info.json`, `vial.json` и проверками
определения. Delete расположен на x=14.0 и правым краем совпадает с Backspace
шириной 2u на x=13.0; промежуток после F12 остаётся 0.25u. Колонка из пяти
навигационных клавиш расположена на x=15.5, стрелка Right остаётся на x=15.25.
ID матрицы нажатия энкодера и двух поворотов не меняются; повороты расположены
на x=16.75 и x=18.0 с промежутком 0.25u. Штатная web-схема Vial не представляет
нажатие энкодера круглым элементом, поэтому ревью не утверждает круглое
отображение. Связанный C52 reader и настоящий GUI `reload_layout`/KLE проходят
101 из 101 проверок; сохранены 83 физические клавиши и два направления энкодера.
HID смоделирован; аппаратная проверка не выполнялась.

Новое независимое ревью охватывает все 15 `HOST_FILES`, особенно шесть изменённых
файлов: packer, transport, release builder, Windows builder, installer и GUI.
Новых ошибок времени выполнения не найдено. Проверяются hashes защищённых
loader/tail и целого factory либо Fn CODE, boot marker и native profile 0.
Смешанный CODE отклоняется. Полная копия 65 536 байт и повторное чтение настроек
предшествуют созданию приватных references. Перед loader transition transport
снова читает весь ROM и требует совпадения с backup. Подготовка по умолчанию No;
точное lowercase `yes` связывает операцию с mode/hash образа. Phase guards
проверяют state/path перед reset, erase и restart. Recovery требует точную личную
сессию и уже видимый loader; автоматических reset/retry/rollback нет.

Закрыты P1 и P2 внешнего OEM capture review: синтетические package/installer
fixtures больше не требуют OEM файлов checkout; настоящий validate_native
проверяется с синтетическими immutable hashes. Независимый повтор Windows:
47 installer/GUI, 17 `test_build*.py`, 64 package (два platform skips), 2 runner —
PASS. Root отдельно повторил Linux/SDCC package: 67 PASS без skips, журнал
`host/runs/rc6-resume-linux-package.log`. Root также обновил private production-pin
проверку: 13 fingerprint/settings/mutation и 6 trial/permanent/restore packing и
readback PASS (`host/runs/rc6-oem-real-fixture-validation.json`). Это отдельный
офлайн уровень, не аппаратное доказательство.

Builder использует локальный `--oem-reference-dir` только для проверки упаковки;
восемь release-файлов не содержат OEM пару. Windows package_files() использует
allowlist host-файлов и связанных manifest входов. Обычный установщик автоматически
получает приватные references из свежего backup; `--reference-dir` необязателен
для точной старой пары владельца. Runtime payload включает 87-байтовый OEM erase
helper из приватного ROM. Исключение references и очистка настроек не означают
отсутствия vendor CODE или неограниченного права распространения. Старые слова о
публичных sanitized references заменены. Новые release approval и Windows
executable проверяются отдельно; это ревью исходников не разрешает прошивку.

Финальная проверка согласованности закрыла два небольших замечания: STATUS
разделяет прежние 43 и текущие 47 тестов; BUILD задаёт новый выходной каталог и
объясняет перенос в фиксированный release path установщика. EN/RU согласованы;
`tools/check_docs.py`: 31 документ, 0 ошибок.

Кандидат с новой геометрией занимает 39 282 CODE (37 423 main и 1 859 low) и
2 071 XRAM. Свободно 1 223 CODE: 1 194 main и 29 low; максимальный адрес кода —
`0xC255`. Прежний образ на 39 262 байта — явно обозначенная предгеометрическая
база сравнения в `SPACE-OPTIONS.md`, а не текущая сборка. Четыре слоя дали те же
размеры CODE/XRAM; полный CIE требует ещё 216 CODE. Это измерения локальной
сборки, отдельно от установленной RC5 и будущих аппаратных проверок.

Личный permanent образ пересобран из точных IHX/MAP новой геометрии и проверенного
trial readback: 51 136 байт, SHA256
`f90a40dcad7364f2278fa5daf2bfa444060140a71401b2c4595bb035aff6aebe`. Packer
подтверждает trial и permanent образы; весь регион NVM 10 240 байт permanent образа
совпадает с readback побайтно (SHA256
`04885d9fcabe876947f003cf82dc246ab83bfcdd878c22d89e30463c48a9bfe5`). Исходный
native restore сохранён. Dirty RAM и незавершённый journal исключены. Снимок может
устареть; локальная подготовка не подтверждает работу RC6 на клавиатуре. Сборка
Windows executable и GUI smoke отмечаются отдельно в статусе.

Сообщение о Fn+F12 разрешено как другая физическая комбинация. Сохранённые
назначения установленной RC5 и восемь CPU сценариев подтверждают прозрачный F12
и RGB toggle на Fn+Delete с обоими порядками отпускания. Изменения прошивки
не потребовались; открытой ошибки RC6 здесь нет.
