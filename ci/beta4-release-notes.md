# AK820 v0.6.0-beta.4

- Caps Word can now start by holding both Shift keys or quickly pressing left Shift twice. It offers saved English and Russian key rules; it does not change or detect the computer's layout.
- Auto Shift in `main` and `typing` now saves its enabled state and selected key categories. Physical `AS_ON`, `AS_OFF` and `AS_TOGG` remain session controls.
- One Shot modifier timeout can be saved from 0 to 30000 ms. Zero keeps it unlimited. One Shot layers, lock and tap-toggle are still unavailable.
- Physical `CM_ON`, `CM_OFF` and `CM_TOGG` now control Combos for the current session without changing saved Combo slots. A mode change releases held keyboard actions; release the keys before pressing again.
- Settings from the immediately preceding beta.3 images can be restored to supported beta.4 images through explicit, exact-image transitions. Other older release images are outside this beta's compatibility scope.

- Caps Word теперь включается при удержании обоих Shift или быстром двойном нажатии левого Shift. Можно сохранить английские или русские правила клавиш; прошивка не определяет и не меняет раскладку компьютера.
- В профилях `main` и `typing` Auto Shift теперь сохраняет состояние и выбранные категории клавиш. Физические `AS_ON`, `AS_OFF` и `AS_TOGG` по-прежнему действуют только до перезапуска.
- Тайм-аут модификатора One Shot можно сохранить в пределах 0–30000 мс. Ноль означает отсутствие тайм-аута. One Shot для слоёв, фиксация и tap-toggle недоступны.
- Физические `CM_ON`, `CM_OFF` и `CM_TOGG` управляют Combo до перезапуска и не меняют сохранённые слоты. При смене режима удерживаемые действия клавиатуры сбрасываются; отпустите клавиши перед новым нажатием.
- Настройки из непосредственно предыдущей beta.3 можно восстановить в поддерживаемые образы beta.4 только по явным переходам между точными образами. Более старые выпуски не входят в область совместимости этой beta.
