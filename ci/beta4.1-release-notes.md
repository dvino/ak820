# AK820 v0.6.0-beta.4.1

- The release catalog authorizes installation of the exact beta.4 firmware images only for configurator versions that explicitly pin this catalog and enforce its image bindings. The currently published configurator remains read-only for beta.4; the compatible configurator update is being prepared separately.
- Firmware images and Python installer code are unchanged from beta.4. This catalog update does not claim hardware validation or authorize writes to saved settings.
