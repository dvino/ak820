# AK820 v0.6.0-beta.5

This beta updates the ten firmware profiles and their exact-image capability and settings catalogs. Typing, Code, Pointer and Multi-OS add Tap Dance; Creative adds NKRO control; Shortcuts adds Dynamic Macros and NKRO control. See the profile documentation for the full feature sets and limitations.

Settings migration recognizes the exact published beta.3, beta.4 and beta.4.1 images as well as the current images; restore targets are current beta.5 images only. Back up settings before updating. Image identity and compatibility checks remain mandatory.

The release is based on offline build, simulator, packing and migration checks. It has **not** been validated on physical hardware. Settings writes remain separately gated; follow the installation guide and retain a recovery backup.
