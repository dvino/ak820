# AK820 v0.6.0-beta.5

This beta updates the ten firmware profiles and their exact-image capability and settings catalogs. Typing, Code, Pointer and Multi-OS add Tap Dance; Creative adds NKRO control; Shortcuts adds Dynamic Macros and NKRO control. See the profile documentation for the full feature sets and limitations.

The candidate's settings migration recognizes the exact published beta.4.1 image identities and current image identities; restore targets must be current beta.5 images. The published beta.4 and beta.4.1 images have identical identities and cannot be distinguished by image identity. Other source identities are unsupported. Back up settings before updating; image identity and compatibility checks remain mandatory.

The replacement candidate has **not yet completed** the required offline qualification and must not be published until the release gates pass. It has **not** been validated on physical hardware. Settings writes remain separately gated; follow the installation guide and retain a recovery backup.
