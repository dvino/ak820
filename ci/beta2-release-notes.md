# AK820 v0.6.0-beta.2

- Choose one of ten firmware profiles in the standalone Windows or Linux installer: `main`, `game`, `mmo`, `typing`, `code`, `pointer`, `onehand`, `creative`, `shortcuts` and `multios`.
- `main` combines QMK Settings, Key Overrides, Leader, temporary macro recording, One Shot, OS indicator control and VialRGB Direct.
- QMK Settings is available in every profile. `game` and `mmo` retain Direct lighting and add NKRO with GUI key lock.
- Other profiles exchange selected `main` modules for Auto Shift, Space Cadet, Grave Escape, Mouse Keys, Tap Dance or temporary modifier mappings.
- English and Russian guides describe each profile and its differences from `main`.

All functions cannot fit in controller memory at once; select a complete profile. The companion application remains in development. Only the matching wired AJAZZ AK820 with a VS11K28A controller is supported; V2, Pro and Max are excluded.

## Русский

- В установщиках Windows и Linux доступен выбор десяти профилей: `main`, `game`, `mmo`, `typing`, `code`, `pointer`, `onehand`, `creative`, `shortcuts` и `multios`.
- `main` объединяет QMK Settings, Key Overrides, Leader, запись временных макросов, One Shot, управление индикатором ОС и VialRGB Direct.
- QMK Settings есть во всех профилях. `game` и `mmo` сохраняют Direct и добавляют NKRO с блокировкой GUI/Win.
- Остальные профили меняют отдельные модули `main` на Auto Shift, Space Cadet, Grave Escape, Mouse Keys, Tap Dance или временную перестановку модификаторов.
- Для каждого профиля есть отдельное описание на русском и английском.

Все функции одновременно не помещаются в память контроллера, поэтому выбирается готовый состав. Приложение-компаньон пока разрабатывается. Поддерживается только соответствующая проводная AJAZZ AK820 с VS11K28A; V2, Pro и Max не поддерживаются.
