- Added a standalone installer for Linux x86_64.
- Added eight configurable two-key Combos in Vial with a 40 ms interval, such as J + K → Escape or F + D → Ctrl+C. [Combo guide](https://github.com/dvino/ak820/blob/v0.6.0-alpha.2/docs/COMBOS.md).
- Settings backup and restore now preserve all eight Combo slots, including empty ones. Backups from older firmware can be restored when the target Combo slots are empty.

- Добавлены восемь настраиваемых комбинаций из двух клавиш в Vial с интервалом 40 мс, например J + K → Escape или F + D → Ctrl+C. [Руководство по Combo](https://github.com/dvino/ak820/blob/v0.6.0-alpha.2/docs/ru/COMBOS.md).
