## Replay

Use Linux/WSL and the pinned toolchain. Create a Python environment from
`qmk-8051-ak820/requirements-ak820-build.txt`; toolchain and LUFA installation
scripts remain under `tools/`. Choose a new build directory for each invocation.
The maximal diagnostic command is:

```sh
python qmk-8051-ak820/util/build_ak820.py \
  --profile maximal --keymap-words-asm --short-calls --tail-share \
  --trim-register-saves --outline-max-helpers 400 --code-end 0x10000 \
  --trim-parameter-spills --parameter-spills-context /path/to/fresh-context.json \
  --nvm-read-block-asm --nvm-update-block-asm \
  --build-dir .build/new-maximal-name \
  --toolchain "$PWD/toolchains/sdcc-4.6.0" --qmk-bin /path/to/venv/bin/qmk
```

For the work control, select `--profile work`, use its own reviewed context and
omit the diagnostic `--code-end` override. The legal CODE ceiling then remains
0xc700. A bootstrap context build omits both parameter-spill options. No command
here flashes or resets a device.

Recreate static and CPU reports with:

```sh
python3 qmk-8051-ak820/tests/ak820_startup/stack_contract.py \
  --build-dir qmk-8051-ak820/.build/resume26b-state-bytes --output /tmp/startup.json
python3 qmk-8051-ak820/tests/ak820_linked_read_hook/check.py \
  --build qmk-8051-ak820/.build/resume26b-state-bytes \
  --analyzer qmk-8051-ak820/tests/ak820_stack/analyze.py --output /tmp/read-hook.json
python3 qmk-8051-ak820/tests/ak820_linked_components/run.py \
  --repo "$PWD" --build "$PWD/qmk-8051-ak820/.build/resume26b-state-bytes" \
  --output /tmp/maximal-components
python3 qmk-8051-ak820/tests/ak820_linked_components/work_irq.py \
  --repo "$PWD" --build "$PWD/qmk-8051-ak820/.build/resume26-work" \
  --output /tmp/work-irq
python3 audits/maximal-continuation-20261025/collect.py \
  --output /tmp/measurements.json
```

Strict linked inventory can select the final stage with explicit
`--ihx`, `--map` and `--reachability` paths; it still validates every retained
manifest artifact first. Replay scripts require the exact matching inputs, not
an image borrowed from another profile. Current compiler-transform options do
not imply release approval.
