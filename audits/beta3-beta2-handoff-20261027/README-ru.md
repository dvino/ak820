# Проверка переноса с beta.2 на beta.3

Приоритет выпуска — перенос настроек с опубликованной beta.2 на beta.3.
Состав десяти профилей, образы, файлы Python и существующий каталог переходов
сохранены. Совместимость с alpha в этой работе не расширяется.

[Скрипт проверки](verify_beta2_handoff.py) сверяет контрольные суммы опубликованных
архива и матрицы beta.2, затем сопоставляет их с готовым пакетом beta.3.
Для десяти исходных и десяти целевых образов проверяются точные идентичности,
разрешённые переходы в каталоге и сохранённые исходные данные проверок.
[Результат](beta2-handoff.json) содержит 100 пар исходного и целевого профилей.

Планы переноса уже выполнены при первоначальной
[подготовке beta.3](../beta3-direct-20261026/transition-preflight.json).
Эта дополнительная проверка подтверждает их соответствие опубликованным файлам;
новые планы восстановления и операции с устройством не выполняются.
Настройки, которые выбранный целевой профиль не поддерживает, по-прежнему
отклоняются.

[Независимое ревью](independent-review.md) охватывает скрипт, его результат
и указанные границы проверки. Готовый ZIP выпуска остаётся действующим.
Небольшой дополнительный Git bundle добавляет только проверку и документацию
поверх коммита `59d323f5d1ca7b15b82b9050223b531056378ede`.
